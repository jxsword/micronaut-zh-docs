# Micronaut 中文文档翻译风格指南

## 核心原则

1. **准确性优先** —— 术语以 config/glossary.yml 为唯一来源；发现新术语先写回术语表再继续
2. **专业性** —— 使用专业技术文档语言，避免口语化
3. **一致性** —— 同一术语全文统一译名；banned 黑名单 0 命中是硬门禁
4. **可读性** —— 符合中文技术文档阅读习惯

## 翻译规则

### 1. 代码与标识符保持原文

| 类型 | 处理方式 | 示例 |
|---|---|---|
| 逐字块（---- ... ----） | 完全保持原文（占位符整块保护） | `micronaut.java.version` 配置示例 |
| 行内代码 | 完全保持原文 | 使用 `BeanContext` 接口 |
| API/类/注解/方法名 | 保持英文原名 | `@Controller`、`ApplicationContext.run` |
| 配置 key / flag / 环境变量 | 保持原文 | `micronaut.server.port`、`--features=jdbc` |
| 依赖坐标 / 版本号 | 保持原格式 | `io.micronaut:micronaut-core:5.2.25` |
| URL / 锚点 | 保持原文 | `xref:guide/a.adoc#x[显示文本可译]` |

### 2. asciidoc 纪律（DR-002 配套）

| 元素 | 处理方式 |
|---|---|
| `include::` / `source::` / `source[]` | 指令行不译，逐字节保留（validate ②） |
| `ifdef/ifndef/ifeval/endif` 条件块 | 标记行不译；块内正文可译 |
| `[[显式锚点]]` / `[#id]` | 不译；翻译被引用标题时按 anchor-registry 原位注入 `[[原锚点]]` |
| `xref:target[label]` / `link:URL[label]` | 目标不译，`[label]` 显示文本可译（应与目标页标题译名一致） |
| 属性定义行 `:name: value` | 不译（整行占位符保护） |
| 表格 `\|===` 定界与 `\|` 分隔符 | 保留；仅译单元格文本 |
| admonition 标记（NOTE:/TIP:/…） | 标记经占位符保护保留，正文译为 注/提示/重要/警告/注意 |
| 标题 `=/==/===` | 层级不变；文本必译（validate ④）；被引用标题注入显式锚点 |
| 语言切换宏 / 代码标签 | 不译 |

### 3. 术语与人称

- 首次出现括注原文：`拦截器（interceptor）`；后续统一用中文译名
- API 名不译；术语表未收录的新术语先写回 glossary.yml
- 人称：读者用「您」，作者用「我们」；指令句「请参阅…」

### 4. 标点与排版

| 规则 | 示例 |
|---|---|
| 中文句子用全角标点（validate ⑦） | 请参阅 `ApplicationContext` 文档。 |
| 中英文/数字之间加空格（validate ⑦） | 使用 `micronaut` CLI、约 2 倍性能 |
| 全角括号不得紧跟行内码等标记（邻接规则） | ❌ 见`x`（详情） ✅ 见 `x`（详情） |
| 代码块内保持原文标点 | 代码块逐字节不动 |
| 禁繁体（validate ⑦） | 软体/資訊 → 软件/信息 |

### 5. 数字与单位

阿拉伯数字；数字与单位间加空格（约 20-30 倍）；版本号保持原格式（v5.2.25）。

## 审校检查清单（reviewer 五项）

- [ ] 漏译/多译逐段对照（新增段、删除段）
- [ ] 术语一致（glossary 命中 + banned 0 命中）
- [ ] 代码块/指令行逐字节 diff 一致
- [ ] xref/锚点可达（registry 注入到位）
- [ ] 溯源元数据（页头引用块 + HTML 注释四字段）齐全且与 manifest 一致

## 争议处理

1. 先查术语表 → 编排方裁决 → 写回 glossary.yml
2. 更新术语表后 validate 全量跑术语扫描
3. 重大分歧记入 decision_log（仅重大时）

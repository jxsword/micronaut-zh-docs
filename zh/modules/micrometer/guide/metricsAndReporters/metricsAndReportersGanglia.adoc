你可以通过 `io.micronaut.micrometer:micronaut-micrometer-registry-ganglia` 引入 Ganglia 上报器

dependency:micronaut-micrometer-registry-ganglia[groupId="io.micronaut.micrometer"]

你可以使用 `micronaut.metrics.export.ganglia` 配置该上报器。最常修改的配置属性如下所列，更多选项请参阅 https://github.com/micrometer-metrics/micrometer/blob/main/implementations/micrometer-registry-ganglia/src/main/java/io/micrometer/ganglia/GangliaConfig.java[GangliaConfig]。

|=======
|*名称* |*说明*
|enabled |是否启用该上报器，例如按环境或为本地开发禁用。默认值：`true`
|protocolVersion | Ganglia 协议版本（`3.0` 或 `3.1`）。默认值：`3.1`。必填。
|step |上报指标的频率。默认值：`PT1M`，即 1 分钟。参见 `java.time.Duration#parse(CharSequence)`
|=======

.Ganglia 配置示例
[configuration]
----
micronaut:
  metrics:
    enabled: true
    export:
      ganglia:
        enabled: true
        protocolVersion: 3.1
        step: PT1M
----

你可以通过 `io.micronaut.micrometer:micronaut-micrometer-registry-kairos` 引入 Kairos 上报器

dependency:micronaut-micrometer-registry-kairos[groupId="io.micronaut.micrometer"]

你可以使用 `micronaut.metrics.export.kairos` 配置该上报器。最常修改的配置属性如下所列，更多选项请参阅 https://github.com/micrometer-metrics/micrometer/blob/main/implementations/micrometer-registry-kairos/src/main/java/io/micrometer/kairos/KairosConfig.java[KairosConfig]。

|=======
|*名称* |*说明*
|enabled |是否启用该上报器，例如按环境或为本地开发禁用。默认值：`true`
|uri | Kairos 服务器 URI。必填。
|step |上报指标的频率。默认值：`PT1M`，即 1 分钟。参见 `java.time.Duration#parse(CharSequence)`
|descriptions | 是否将 meter 描述发送到 Kairos。禁用可减少每次抓取发送的数据量。默认值：`true`
|=======

.Kairos 配置示例
[configuration]
----
micronaut:
  metrics:
    enabled: true
    export:
      kairos:
        enabled: true
        uri: http://localhost:8080/api/v1/datapoints
        step: PT1M
----

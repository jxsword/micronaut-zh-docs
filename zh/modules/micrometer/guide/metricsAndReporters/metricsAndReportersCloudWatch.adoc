你可以通过 `io.micronaut.micrometer:micronaut-micrometer-registry-cloudwatch` 引入 CloudWatch 上报器

dependency:micronaut-micrometer-registry-cloudwatch[groupId="io.micronaut.micrometer"]

你可以使用 `micronaut.metrics.export.cloudwatch` 配置该上报器。最常修改的配置属性如下所列，更多选项请参阅 https://github.com/micrometer-metrics/micrometer/blob/main/implementations/micrometer-registry-cloudwatch/src/main/java/io/micrometer/cloudwatch/CloudWatchConfig.java[CloudWatchConfig]。

|=======
|*名称* |*说明*
|enabled |是否启用该上报器，例如按环境或为本地开发禁用。默认值：`true`
|namespace |这批指标在 CloudWatch 中显示的命名空间。默认值：`micronaut`。
|batchSize |单批发送到 CloudWatch 的指标数量。默认值：`20`。上限与 https://docs.aws.amazon.com/AmazonCloudWatch/latest/APIReference/API_MetricDatum.html[CloudWatch API 参考] 一致。
|=======

.CloudWatch 配置示例
[configuration]
----
micronaut:
  metrics:
    enabled: true
    export:
      cloudwatch:
        enabled: true
        namespace: myAwesomeAppMetrics
        batchSize: 10
----

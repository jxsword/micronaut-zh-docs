你可以通过 `io.micronaut.micrometer:micronaut-micrometer-registry-azure-monitor` 引入 Azure Monitor 上报器

dependency:micronaut-micrometer-registry-azure-monitor[groupId="io.micronaut.micrometer"]

你可以使用 `micronaut.metrics.export.azuremonitor` 配置该上报器。最常修改的配置属性如下所列，更多选项请参阅 https://github.com/micrometer-metrics/micrometer/blob/main/implementations/micrometer-registry-azure-monitor/src/main/java/io/micrometer/azuremonitor/AzureMonitorConfig.java[AzureMonitorConfig]。

|=======
|*名称* |*说明*
|enabled |是否启用该上报器，例如按环境或为本地开发禁用。默认值：`true`
|instrumentationKey | Azure Monitor 插桩密钥（instrumentation key）。必填。
|step |上报指标的频率。默认值：`PT1M`，即 1 分钟。参见 `java.time.Duration#parse(CharSequence)`
|=======

.Azure Monitor 配置示例
[configuration]
----
micronaut:
  metrics:
    enabled: true
    export:
      azuremonitor:
        enabled: true
        instrumentationKey: ${AZUREMONITOR_INSTRUMENTATION_KEY}
        step: PT1M
----

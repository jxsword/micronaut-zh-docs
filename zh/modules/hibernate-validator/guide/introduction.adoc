`micronaut-hibernate-validator` 模块提供对使用 Hibernate Validator 校验 Micronaut bean 的支持。

使用 Hibernate Validator 将创建一个 `jakarta.validation.ValidatorFactory` bean，它能够校验 Micronaut bean 上的 `jakarta.validation` 注解。

请参阅文档中的 https://docs.micronaut.io/latest/guide/index.html#beanValidation[Bean Validation] 章节，了解如何声明 bean 校验规则。

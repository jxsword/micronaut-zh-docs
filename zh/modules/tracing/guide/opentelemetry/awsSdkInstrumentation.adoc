要为 https://aws-otel.github.io/docs/getting-started/java-sdk/trace-manual-instr#instrumenting-the-aws-sdk[AWS SDK] 插桩，请加入以下依赖：

dependency:opentelemetry-aws-sdk-2.2[groupId=io.opentelemetry.instrumentation,scope=compile]

此外，请加入 https://micronaut-projects.github.io/micronaut-aws/latest/guide/#sdkv2[Micronaut AWS SDK v2] 依赖：

dependency:micronaut-aws-sdk-v2[groupId=io.micronaut.aws,scope=compile]

`micronaut-aws-sdk-v2` 依赖会创建 `SdkClientBuilder` 类型的 bean。为给 AWS SDK 插桩，Micronaut OpenTelemetry 会通过 bean 创建监听器，为 `SdkClientBuilder` 类型的 bean 注册一个追踪拦截器。

== ID 生成器

某些自定义供应商可能要求跨度 traceId 采用与默认格式不同的格式。您可以提供自己的 https://github.com/open-telemetry/opentelemetry-java/blob/main/sdk/trace/src/main/java/io/opentelemetry/sdk/trace/IdGenerator.java[IdGenerator] 类型的 bean。
例如，AWS X-Ray 要求其追踪标识符采用特定格式。请添加以下依赖，将 https://github.com/open-telemetry/opentelemetry-java/blob/main/sdk-extensions/aws/src/main/java/io/opentelemetry/sdk/extension/aws/trace/AwsXrayIdGenerator.java[AwsXrayIdGenerator] 实例注册为 https://github.com/open-telemetry/opentelemetry-java/blob/main/sdk/trace/src/main/java/io/opentelemetry/sdk/trace/IdGenerator.java[IdGenerator] 类型的 bean：

dependency:opentelemetry-aws-xray[scope="implementation", groupId="io.opentelemetry.contrib"]

要将追踪数据成功导出到 AWS X-Ray，您必须运行 https://github.com/aws-observability/aws-otel-collector[AWS Open Telemetry Collector]，由它定期将追踪数据发送到 AWS。

在您的项目中可以指定要使用的传播器。默认值设为 "tracecontext, baggage"。可用值定义在 https://github.com/open-telemetry/opentelemetry-java/blob/main/sdk-extensions/autoconfigure/README.md[Open Telemetry Autoconfigure SDK 文档] 中。

要在应用中使用 https://docs.aws.amazon.com/xray/latest/devguide/xray-concepts.html#xray-concepts-tracingheader[AWS X-Ray] 传播器，您需要在项目中添加以下依赖：

dependency:opentelemetry-extension-aws[scope="implementation", groupId="io.opentelemetry"]

并且必须在配置文件中添加 "xray"。

[configuration]
----
otel:
  traces:
    exporter: otlp
  propagators: tracecontext, baggage, xray
----

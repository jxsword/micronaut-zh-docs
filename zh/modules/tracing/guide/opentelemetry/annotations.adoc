pkg:tracing.opentelemetry.processing[] 包包含转换器与映射器，支持使用 Open Telemetry 注解。

NOTE: 自 Micronaut Tracing `4.5.0` 起，OpenTelemetry 的 `@WithSpan` 与 `@SpanAttribute` 注解必须从 `io.opentelemetry.instrumentation.annotations` 引入。仍在引入 `io.opentelemetry.extension.annotations` 的旧应用在升级时需要更新这些引入。

要启用 Open Telemetry 注解，您需要在依赖块中添加以下注解处理器：
dependency:micronaut-tracing-opentelemetry-annotation[scope="annotationProcessor", version="{version}", groupId="io.micronaut.tracing"]

pkg:tracing.annotation[] 包中定义的 Open Tracing 注解同样可以在 Open Telemetry 中使用。

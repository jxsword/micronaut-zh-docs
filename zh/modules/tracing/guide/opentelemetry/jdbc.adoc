[[jdbc]]
要在每个 JDBC 查询上创建跨度对象，请添加以下依赖：
dependency:micronaut-tracing-opentelemetry-jdbc[scope="implementation", groupId="io.micronaut.tracing"]

该依赖为 `javax.sql.DataSource` bean 插桩，拦截对数据库的查询。

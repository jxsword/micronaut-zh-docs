[[keys]]
NOTE: 只有使用 JWT 认证时才能启用该控制器。

https://tools.ietf.org/html/rfc7517[JSON Web Key（JWK）] 是一种表示加密密钥的 JSON 对象。对象的成员表示密钥的属性，包括密钥的值。

与此同时，JWK Set 是表示一组 JWK 的 JSON 对象。该 JSON 对象必须有一个 "keys" 成员，它是 JWK 的数组。

要启用 link:{api}/io/micronaut/security/token/jwt/endpoints/KeysController.html[KeysController]，您至少要提供一个 link:{api}/io/micronaut/security/token/jwt/endpoints/JwkProvider.html[JwkProvider] 类型的 bean。

此外，您可以通过以下方式配置它：

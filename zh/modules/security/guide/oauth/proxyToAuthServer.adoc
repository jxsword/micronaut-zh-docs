您可以将发往 `/.well-known/oauth-authorization-server` https://datatracker.ietf.org/doc/html/rfc8414[RFC8414] 与 `/.well-known/openid-configuration` https://openid.net/specs/openid-connect-discovery-1_0.html[OpenID Connect 发现（Discovery）] 的 GET 请求代理到授权服务器。

image::proxy.svg[]

要启用代理，请将以下配置属性设为 `true`：

|===
| 代理路径 | 属性
| `/.well-known/oauth-authorization-server`
| `micronaut.security.oauth2.clients.*.proxy-well-known-oauth-authorization-server`
| `/.well-known/openid-configuration`
| `micronaut.security.oauth2.clients.*.proxy-well-known-openid-configuration`
|===

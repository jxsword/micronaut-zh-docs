本库默认不会在授权请求中包含 https://openid.net/specs/openid-connect-core-1_0.html#IDToken[login hint]。可以注册一个 api:io.micronaut.security.oauth2.endpoint.authorization.request.LoginHintResolver[] bean，在构建授权请求时会被调用。

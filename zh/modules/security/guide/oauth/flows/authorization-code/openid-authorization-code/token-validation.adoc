api:security.oauth2.endpoint.token.response.validation.OpenIdTokenResponseValidator[] bean 负责校验 JWT 令牌。默认实现尽可能遵循 OpenID Connect 规范中关于 https://openid.net/specs/openid-connect-core-1_0.html#IDTokenValidation[令牌校验（token validation）] 的指南。

默认情况下，api:io.micronaut.security.token.jwt.validator.GenericJwtClaimsValidator[] 与 api:io.micronaut.security.oauth2.endpoint.token.response.validation.OpenIdClaimsValidator[] 的所有实现都会用于校验令牌。

要允许额外的或自定义的校验，请注册一个 api:io.micronaut.security.oauth2.endpoint.token.response.validation.OpenIdClaimsValidator[] bean。

[[openid-configuration]]
使用 OpenID 提供者进行授权的要求是：

* 配置 client id 和 secret
* 配置 issuer

[configuration]
----
micronaut:
    security:
        oauth2:
            clients:
                okta:
                    client-id: <<my client id>>
                    client-secret: <<my client secret>>
                    openid:
                        issuer: <<my openid issuer>>
----

- 配置一个客户端。名称 `okta` 是任意的
- 提供 `client-id` 与 `client-secret` 的值
- 指定 OpenID 提供者的 issuer URL

issuer URL 将用于发现提供者暴露的端点。

TIP: 要在任意给定环境中禁用特定客户端，请在该客户端配置内设置 `enabled: false`。

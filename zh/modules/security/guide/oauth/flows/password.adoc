资源所有者密码凭证许可（resource owner password credentials grant）在 https://tools.ietf.org/html/rfc6749#section-4.3[RFC 6749] 中有描述。简而言之，凭证被直接传递给令牌端点，如果认证成功，令牌端点会响应相应的令牌。

对令牌响应的后续处理，在授权码许可与密码许可之间是相同的。请查看以下高层流程图：

image::oauth-password.svg[]

OpenID 提供者

image::openid-password.svg[]

在 Micronaut 中，通过在客户端配置中设置 `grant-type` 配置选项来支持密码许可。例如：

[configuration]
----
micronaut:
  security:
    oauth2:
      clients:
        github:
          grant-type: password
----

NOTE: 上面的示例并非完整的配置参考

当客户端配置为密码许可类型时，授权码端点将不可用，取而代之的是会创建一个 api:security.authentication.AuthenticationProvider[]，参与 <<login, 正常登录流程>>。

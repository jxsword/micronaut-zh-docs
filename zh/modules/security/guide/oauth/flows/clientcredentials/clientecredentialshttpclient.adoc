Micronaut Security 包含 api:security.oauth2.client.clientcredentials.propagation.ClientCredentialsHttpClientFilter[]。这个 https://docs.micronaut.io/latest/guide/index.html#clientFilter[HTTP 客户端过滤器] 使您能够在传出请求的 HTTP Header 中自动附加访问令牌。它通过客户端凭证请求获取访问令牌。

例如，下面的配置会为通过 HTTP 客户端 `inventory` 发出的请求 HTTP Header 添加访问令牌。它使用 OAuth 2.0 客户端 `companyauthserver` 发起客户端凭证请求来获取该访问令牌。

[configuration]
----
micronaut:
  security:
    oauth2:
      clients:
        companyauthserver:
          client-id: 'XXX'
          client-secret: 'YYY'
          client-credentials:
            service-id-regex: 'inventory'
          token:
            url: "https://foo.bar/token"
            auth-method: client_secret_basic
----

Micronaut Security 提供 `micronaut-security-ojdbc-extensions` 模块，用于与 https://github.com/oracle/ojdbc-extensions[Oracle JDBC 驱动扩展（Oracle JDBC Driver Extensions）] 集成。
该模块注册一个 https://docs.oracle.com/en/database/oracle/oracle-database/26/jajdb/oracle/jdbc/spi/EndUserSecurityContextProvider.html[Oracle JDBC `EndUserSecurityContextProvider`]。

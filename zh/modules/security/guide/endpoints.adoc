<<securityFilter,安全过滤器>> 一节描述了如何为每个请求解析出 api:security.authentication.Authentication[]。它可能是位于 HTTP Header、Cookie 或 HTTP 会话中的令牌。
那么，您如何获得这样的令牌？或者说，用户最初是如何被保存进 HTTP 会话的？在 Micronaut 应用中，您可以暴露 <<loginController,LoginController>>。

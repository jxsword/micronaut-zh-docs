Micronaut Security 包含以下新特性与改进。

== Micronaut Security 3 的新特性

- 多个 API 均有改进
- 认证状态被整合到单一接口中
- api:security.rules.SecurityRule[] API 现已是响应式的
- api:security.authentication.Authentication[] 新增了 `getRoles` 方法
- api:security.authentication.Authentication[] 与 api:security.authentication.AuthenticationResponse[] 新增了若干静态方法，用于帮助创建认证相关对象

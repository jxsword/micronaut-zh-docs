[[logout]]
要启用登出控制器，您需要有一个 api:security.handlers.LogoutHandler[] 类型的 bean。控制器的行为将委托给它。
当然，也可以提供自定义实现。不过，已有多种 <<logoutHandler,登出处理器>> 实现开箱即用。

您可以通过以下方式配置登出端点：

include::{includedir}configurationProperties/io.micronaut.security.endpoints.LogoutControllerConfigurationProperties.adoc[]

TIP: 如果您使用的 JWT 认证不存储在 Cookie 中，则可能无需调用 `/logout` 端点，因为登出通常只是删除客户端中的 JWT 令牌。

您可以提供自己的 api:security.handlers.LoginHandler[] 与 api:security.handlers.LogoutHandler[] 实现。
不过，Micronaut Security 各模块内置了多种实现，通过设置配置 `micronaut.security.authentication` 即可启用。

|===
| `micronaut.security.authentication` 值 | 所需模块 | 登录处理器 | 登出处理器

| `cookie`
| `micronaut-security`
| api:security.token.cookie.TokenCookieLoginHandler[]
| api:security.token.cookie.TokenCookieClearerLogoutHandler[]

| `session`
| `micronaut-session`
| api:security.session.SessionLoginHandler[]
| api:security.session.SessionLogoutHandler[]

| `bearer`
| `micronaut-jwt`
| api:security.token.bearer.AccessRefreshTokenLoginHandler[]
|

| `idtoken`
| `micronaut-oauth`
| api:security.oauth2.endpoint.token.response.IdTokenLoginHandler[]
|
|===

[[micronautSecurityAuthenticationCookie]]
设置 `micronaut.security.authentication=cookie` 后，会启用 api:security.token.cookie.TokenCookieLoginHandler[]——一个 api:security.handlers.LoginHandler[] 类型的 bean，以及 api:security.token.jwt.cookie.JwtCookieClearerLogoutHandler[]——一个 api:security.handlers.LogoutHandler[] 类型的 bean。

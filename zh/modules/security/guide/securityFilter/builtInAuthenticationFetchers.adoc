您可以编写自己的 api:security.filters.AuthenticationFetcher[] 类型 bean。不过，Micronaut Security 内置了若干认证获取器：

|===
| Bean | 说明
| api:io.micronaut.security.authentication.BasicAuthAuthenticationFetcher[]
| 它从使用 Basic 认证的 HTTP 请求中解析凭证，然后用解析出的凭证调用每个认证提供者。
| api:io.micronaut.security.token.TokenAuthenticationFetcher[]
| 它尝试从 HTTP 请求中获取令牌，随后尝试验证该令牌。
| api:io.micronaut.security.session.SessionAuthenticationFetcher[]
| 它尝试从 HTTP 会话中获取 api:security.authentication.Authentication[]。
| api:io.micronaut.security.x509.X509AuthenticationFetcher[]
| 当存在 X.509 客户端证书且能够提取出名称（CN）时，创建 api:security.authentication.Authentication[]。
|===

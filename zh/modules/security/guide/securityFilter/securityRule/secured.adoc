[[secured]]
如下所示，您可以使用 ann:security.annotation.Secured[] 注解来控制对控制器或控制器方法的访问。

<1> 已认证的用户可以访问 `authenticated` 控制器的动作。
<2> 被授予 `ROLE_ADMIN` 或 `ROLE_X` 角色的用户可以访问 `withroles` 控制器的动作。
<3> 匿名用户（无论是否认证）都可以访问 `anonymous` 控制器的动作。

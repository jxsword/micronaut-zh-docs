如果您需要在控制器之外访问当前已认证的用户，可以注入 api:security.utils.SecurityService[] bean，它提供了一组与认证和授权相关的便捷方法。

在底层，它使用 api:security.context.SecurityContextHolder[] 与 api:security.context.SecurityContext[] API。

`SecurityContext` 的默认提供者使用服务器请求属性。您可以通过 https://docs.oracle.com/javase/tutorial/ext/basics/spi.html[Java SPI] 提供 api:io.micronaut.security.context.SecurityContextSupplier[] 的实现来替换它。

=== 在 Project Reactor 中使用 SecurityService

如果您使用 Micronaut Reactor 并在响应式链中访问 api:security.utils.SecurityService[]，请添加以下依赖以处理 https://docs.micronaut.io/latest/guide/#reactorContextPropagation[Reactor 上下文传播（Reactor Context Propagation）]。

dependency:context-propagation[groupId=io.micrometer]

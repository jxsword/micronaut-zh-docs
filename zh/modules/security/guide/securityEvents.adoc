Micronaut security 类会生成多个 https://micronaut-projects.github.io/micronaut-core/latest/api/io/micronaut/context/event/ApplicationEvent.html[ApplicationEvent]（应用事件），您可以订阅这些事件。

|===

| 事件名称 | 描述

| link:{api}/io/micronaut/security/event/LoginFailedEvent.html[LoginFailedEvent] | 登录失败时触发。

| link:{api}/io/micronaut/security/event/LoginSuccessfulEvent.html[LoginSuccessfulEvent] | 登录成功时触发。

| link:{api}/io/micronaut/security/event/LogoutEvent.html[LogoutEvent] | 用户登出时触发。

| link:{api}/io/micronaut/security/event/TokenValidatedEvent.html[TokenValidatedEvent] | 令牌被验证时触发。

| link:{api}/io/micronaut/security/token/event/AccessTokenGeneratedEvent.html[AccessTokenGeneratedEvent] | JWT 访问令牌生成时触发。

| link:{api}/io/micronaut/security/token/event/RefreshTokenGeneratedEvent.html[RefreshTokenGeneratedEvent] | JWT 刷新令牌生成时触发。

|===

要了解如何监听事件，请参阅文档的 https://docs.micronaut.io/latest/guide/index.html#contextEvents[上下文事件（Context Events）] 一节。

[[securityFilter]]
添加 `micronaut-security` 依赖后，它会提供一个 https://docs.micronaut.io/latest/guide/#filters[Micronaut HTTP 服务器过滤器]——api:security.filters.SecurityFilter[]。

image::securityfilter.png[]

对于每个请求，该过滤器会将请求与每个 api:security.filters.AuthenticationFetcher[] 类型的 bean 进行评估。评估结果可能解析出一个 api:security.authentication.Authentication[] 实例。

随后，这个可选的认证信息会与每个 api:security.rules.SecurityRule[] 类型的 bean 进行评估，以判定请求是否获得授权。若未授权，则抛出 api:security.authentication.AuthorizationException[]。

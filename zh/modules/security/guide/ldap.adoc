Micronaut 开箱即支持使用 LDAP 进行认证。要开始使用，请为您的应用添加 `security-ldap` 依赖。

.build.gradle
[source,groovy]
----
compile "io.micronaut.security:micronaut-security-ldap"
----

TIP: 请阅读 https://guides.micronaut.io/latest/micronaut-database-authentication-provider.html[LDAP 与数据库认证提供者] 查看示例。

将 `micronaut.security.ldap.enabled` 设为 `false` 可全局禁用 LDAP 认证，也可以按提供者单独禁用，例如 `micronaut.security.ldap.default.enabled: false`。

IMPORTANT: https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html#signed-double-submit-cookie-recommended[带签名的双重提交 Cookie]。对 CSRF Token 进行签名，以防止攻击者用自己的值覆盖该 Cookie 的值（例如通过子域名接管攻击）。

要对 CSRF Token 签名，请设置属性 `micronaut.security.csrf.signature-key`。

[configuration]
----
micronaut:
  security:
    csrf:
      signature-key: pleaseChangeThisSecretForANewOnekoqQ-EstJQLr_T-1qS0gZH75aKtMN3Yj0iPS4hcgUuTwjAzZr1Z9CAow
----

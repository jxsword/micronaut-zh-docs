____
在同步令牌模式中，服务器生成一个 CSRF token 并在返回之前与客户端共享它，
通常通过关联操作的隐藏表单参数传递。在表单提交时，服务器将该 CSRF token 与用户会话中存储的
token 进行比对。如果二者匹配，则批准该请求；否则拒绝该请求

Micronaut Security CSRF 自带 `io.micronaut.security.csrf.resolver.FieldCsrfTokenResolver`——一个 api:security.csrf.resolver.CsrfTokenResolver[] 的实现，它会在请求的表单 URL 编码字段中查找 CSRF Token。

[source, bash]
----
POST /transfer HTTP/1.1
Host: vulnerable bank
Content-Type: application/x-www-form-urlencoded
Cookie: session=<token>
[...]
amount=100&toUser=intended&csrfToken=o24b65486f506e2cd4403caf0d640024
----

你可以通过设置 `micronaut.security.csrf.token-resolvers.field.enabled=false` 来禁用它

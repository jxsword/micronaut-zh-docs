Micronaut Security CSRF 实现的核心是 `io.micronaut.security.csrf.filter.CsrfFilter`。
它是一个 https://docs.micronaut.io/latest/guide/#filters[服务器过滤器]，会尝试使用每个 api:security.csrf.resolvers.CsrfTokenResolver[] 类型的 bean 来解析 CSRF Token，并用 api:security.csrf.validator.CsrfTokenValidator[] 类型的 bean 校验它。

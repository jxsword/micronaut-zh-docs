提供了 ann:security.annotation.CreatedBy[] 与 ann:security.annotation.UpdatedBy[] 两个注解，可应用于您的 Micronaut Data 实体。被标注的字段会自动填充为当前已认证用户的身份。例如：

snippet::io.micronaut.security.audit.docs.createdby.Book[tags="clazz"]
<1> 该类由 Micronaut Data 进行映射与持久化
<2> creator 字段会在 `save()` 时填充
<3> editor 字段会在 `save()` 和 `update()` 时填充

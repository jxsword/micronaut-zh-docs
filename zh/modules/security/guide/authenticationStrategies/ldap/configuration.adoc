Micronaut 的 LDAP 认证支持配置一个或多个用于身份验证的 LDAP 服务器。每个服务器都有自己的设置，并且可以启用或禁用。

TIP: 要使用 SSL 连接 LDAP 服务器，请将标准 Java 系统属性设置为适合你服务器的值。
```
-Djavax.net.ssl.trustStore="<path to truststore file>"
-Djavax.net.ssl.trustStorePassword="<passphrase for truststore>"
```

你可以指定以 `classpath:` 或 `file:` 开头的路径，从磁盘或类路径的任意位置提供 JSON JWKS。例如，要从 `src/main/resources/jwks/certs.json` 提供静态资源，你可以使用 `classpath:jwks/certs.json` 作为路径。

[[jwks]]
https://tools.ietf.org/html/rfc7517[JSON Web Key（JWK）] 是一个表示加密密钥的 JSON 对象。你可以使用远程 JWK Set——表示一组 JWK 的 JSON 对象——来验证 JWT 签名。

上面的代码片段创建了一个带 `awscognito` 名称限定符的 link:{api}/io/micronaut/security/token/jwt/nimbus/ReactiveJwksSignature.html[ReactiveJwksSignature] bean。

如果类路径上有 https://docs.micronaut.io/latest/guide/#httpClient[Micronaut HTTP Client]，则将使用它来获取远程 JWK Set。这样在获取资源时可以应用 HTTP 客户端的配置设置。如果存在命名的服务专属客户端，且该服务的名称与配置的 JWKS 提供者名称匹配，则使用该特定客户端实例；否则使用默认的 HTTP 客户端实例（应用 `micronaut.http.client.*` 的任何全局配置设置）。如果类路径上没有 Micronaut HTTP Client，则该实现将回退到外部 JWT 库依赖的内部资源获取机制。

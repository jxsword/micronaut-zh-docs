API api:io.micronaut.security.token.jwt.validator.JsonWebTokenValidator[] 与 api:io.micronaut.security.token.jwt.validator.ReactiveJsonWebTokenValidator[] 可用于验证 JWT 令牌。

验证会执行以下步骤：

* - 解析令牌（若已加密，则先解密）。
* - 验证签名
* - 使用 api:security.token.jwt.validator.GenericJwtClaimsValidator[] 类型的 bean 验证 Claims。

`JsonWebTokenValidator` 不会使用远程签名配置。例如，它不会使用远程 JWK 验证签名。
只有 api:io.micronaut.security.token.jwt.validator.ReactiveJsonWebTokenValidator[] 实现了
api:io.micronaut.security.token.validator.TokenValidator[]。

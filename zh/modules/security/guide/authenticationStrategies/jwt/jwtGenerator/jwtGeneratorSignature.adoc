要生成已签名的 JWT，你需要在应用中提供一个
link:{api}/io/micronaut/security/token/jwt/signature/rsa/RSASignatureGeneratorConfiguration.html[RSASignatureGeneratorConfiguration]、
link:{api}/io/micronaut/security/token/jwt/signature/ec/ECSignatureGeneratorConfiguration.html[ECSignatureGeneratorConfiguration]
或
link:{api}/io/micronaut/security/token/jwt/signature/secret/SecretSignatureConfiguration.html[SecretSignatureConfiguration] 类型的 bean，它们必须**用 `@Named` `generator` https://docs.micronaut.io/latest/guide/index.html#qualifiers[限定]**，因为这些配置 bean 会被工厂（
link:{api}/io/micronaut/security/token/jwt/signature/rsa/RSASignatureGeneratorFactory.html[RSASignatureGeneratorFactory]、
link:{api}/io/micronaut/security/token/jwt/signature/ec/ECSignatureGeneratorConfiguration.html[ECSignatureGeneratorFactory]）或其他使用
https://docs.micronaut.io/latest/guide/index.html#eachBean[@EachBean] 驱动配置的 bean（link:{api}/io/micronaut/security/token/jwt/signature/secret/SecretSignature.html[SecretSignature]）所使用。

IMPORTANT: 记得用 `@Named` `generator` 限定你希望用来签名 JSON Web 令牌的签名配置 bean。

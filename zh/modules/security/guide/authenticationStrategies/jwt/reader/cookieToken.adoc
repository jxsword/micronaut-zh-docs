你也可以通过 Cookie 来发送/读取 JWT 令牌。

下面的时序图展示了认证流程：

image::jwt-cookie.svg[]

默认情况下，从 Cookie 读取令牌是禁用的。注意：要使用来自 Cookie 的 JWT 令牌，需要启用 JWT 认证。

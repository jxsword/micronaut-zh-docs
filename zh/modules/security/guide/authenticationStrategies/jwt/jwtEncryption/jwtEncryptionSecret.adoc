你可以通过配置轻松设置一个用 `@Named` `generator` 限定的 link:{api}/io/micronaut/security/token/jwt/encryption/secret/SecretEncryptionConfiguration.html[SecretEncryptionConfiguration]：

[configuration]
----
micronaut:
  security:
    token:
      jwt:
        encryptions:
          secret:
            generator:
              secret: pleaseChangeThisSecretForANewOne
              jwe-algorithm: dir
              encryption-method: A256GCM
----

- **将 `secret` 属性改为你自己的密钥并妥善保管**。
- `jwe-algorithm` 指定 JSON Web Encryption 算法。本例中为 `dir`，即使用共享对称密钥的直接加密。
- `encryption-method` 指定加密方法。本例中为 `A256GCM`，即使用 256 位密钥的 AES GCM。

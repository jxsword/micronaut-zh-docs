[[basicAuth]]
开箱即用，Micronaut 支持 https://tools.ietf.org/html/rfc7617[RFC7617]，它定义了 "Basic" 超文本传输协议（HTTP）认证方案，该方案以 user-id/password 对的形式传输凭证，并使用 Base64 编码。

只要您有任何 <<authenticationProviders,认证提供者>>，基本认证就默认启用。您可以通过将 `micronaut.security.basic-auth.enabled` 设置为 `false` 来禁用它。

[source, bash]
.使用 Basic Auth 的 cURL 命令
----
curl "http://localhost:8080/info" \
     -u 'user:password'
----

从 HTTP Header 中读取凭证之后，凭证会被送入一个 link:{api}/io/micronaut/security/authentication/Authenticator.html[Authenticator] 进行验证尝试。

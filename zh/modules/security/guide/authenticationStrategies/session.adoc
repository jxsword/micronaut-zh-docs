Micronaut 支持基于会话的认证。

[TIP]
.使用 CLI
====
如果您正使用 Micronaut CLI 创建项目，请提供 `security-session` 特性来在项目中配置会话安全：
----
$ mn create-app my-app --features security-session
----
====


要使用 Micronaut 基于会话的认证能力，类路径中必须有 `security-session` 依赖。例如：

dependency:io.micronaut.security:micronaut-security-processor[scope='annotationProcessor']

dependency:io.micronaut.security:micronaut-security-session[]

NOTE: 仅在使用 JSR 250 注解时才需要 `micronaut-security-processor` 依赖

== 无重定向的基于会话认证

将 `micronaut.security.authentication` 设置为 `session` 时，会启用 api:security.session.SessionLoginHandler[] 与 api:security.session.SessionLogoutHandler[]。

这些处理器会向 <<redirection,重定向配置>> 中定义的 URL 返回 303 响应。通过 `micronaut.security.redirect.enabled=false` 禁用重定向配置后，将改为返回 200 响应。

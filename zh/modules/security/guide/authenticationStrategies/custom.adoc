所有认证策略都实现 api:security.filters.AuthenticationFetcher[] 接口。该契约的设计目的是从请求中返回 api:security.authentication.Authentication[]。要实现自定义逻辑来获取当前登录的用户，只需创建一个实现该契约的 bean，它就会被自动发现并使用。

例如，如果你使用 https://www.broadcom.com/products/cyber-security/identity/siteminder[SiteMinder] 这样为你处理认证的产品，你可以确信访问你应用的用户已通过认证，并且可以通过 `SM_USER` 请求头访问他们的用户名，并据此构建 `Authentication`：

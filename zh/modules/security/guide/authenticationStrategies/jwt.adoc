Micronaut 提供了基于 https://jwt.io/[JSON Web Token（JWT）] 的安全能力。
JWT 是一项 https://tools.ietf.org/html/rfc7519[IETF 标准]，它定义了一种在不安全 URL 上传输任意数据的安全的封装方式。

[TIP]
.使用 CLI
====
如果您正使用 Micronaut CLI 创建项目，请提供 `security-jwt` 特性来在项目中配置 JWT 支持：
----
$ mn create-app my-app --features security-jwt
----
====

要使用 Micronaut 基于 JWT 的认证能力，类路径中必须有 `security-jwt` 依赖。例如：

dependency:io.micronaut.security:micronaut-security-processor[scope='annotationProcessor']

dependency:io.micronaut.security:micronaut-security-jwt[]

NOTE: 仅在使用 JSR 250 注解时才需要 `micronaut-security-processor` 依赖

以下配置属性可用于自定义基于 JWT 的认证行为：

== JWT 长什么样？

image::jwt.png[]

===  Header

一个类似下面这样的 base64 编码 JSON：

[source, json]
.JWT header
----
{
    "alg": "HS256",
    "typ": "JWT"
}
----

=== Claims

一个类似下面这样的 base64 编码 JSON：

[source, json]
.JWT claims
----
{
    "exp": 1422990129,
    "sub": "jimi",
    "roles": [
        "ROLE_ADMIN",
        "ROLE_USER"
    ],
    "iat": 1422986529
}
----

=== Signature

取决于 header 中指定的算法，它可以是 base64 编码的 header 与 claims 的数字签名，也可以是它们的加密结果。

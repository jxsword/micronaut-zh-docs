Micronaut 为 LDAP（api:security.ldap.LdapAuthenticationProvider[]）以及 OAuth 2.0 密码授权认证流程（api:security.oauth2.endpoint.token.request.password.OauthPasswordAuthenticationProvider[] 与 api:security.oauth2.endpoint.token.request.password.OpenIdPasswordAuthenticationProvider[]）提供了内置认证提供者。对于任何自定义认证，则必须创建一个认证提供者。

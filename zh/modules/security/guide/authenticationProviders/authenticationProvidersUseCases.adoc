内置的 <<login,登录控制器>> 会使用所有可用的认证提供者。第一个返回成功认证响应的提供者，其返回值将被用作 JWT 令牌或会话状态的基础。

以 api:security.filters.AuthenticationFetcher[] 形式实现的基本认证也会触发可用的 api:security.authentication.AuthenticationProvider[]。

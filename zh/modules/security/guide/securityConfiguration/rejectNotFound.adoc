默认情况下，引入 Micronaut Security 后，即使是不存在的路由，应用也返回 401 或 403。该行为可防止攻击者探测应用中存在哪些端点。不过，如果希望对不存在的路由返回 404，可以在配置中设置 `micronaut.security.reject-not-found: false`。

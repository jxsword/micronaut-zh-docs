一些内置处理器会以 303（See Other）响应跳转到 <<redirection,重定向配置>> 中定义的 URL。
如果通过将 `micronaut.security.redirect.enabled` 设置为 `false` 来禁用重定向配置，这些处理器将改为返回 200 响应。

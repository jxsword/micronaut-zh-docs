默认情况下，Micronaut 只要求一个 <<authenticationProviders,认证提供者>> 返回成功的认证响应。您可以设置 `micronaut.security.authentication-provider-strategy: ALL`，要求所有 api:security.authentication.AuthenticationProvider[] 都返回成功的认证响应。

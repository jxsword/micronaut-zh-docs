要使用该模块，请添加以下依赖：

dependency:micronaut-security-ojdbc-extensions[groupId=io.micronaut.security]

此外，您必须添加一个 HTTP 客户端实现：https://docs.micronaut.io/latest/guide/#nettyHttpClient[基于 Netty 的 HTTP 客户端] 或 https://docs.micronaut.io/latest/guide/#jdkHttpClient[JDK HTTP 客户端] 二者之一。

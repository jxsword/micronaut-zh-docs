对于 Micronaut Session 5.x，`HttpSessionFilter` 是一个 https://docs.micronaut.io/latest/guide/#filtermethods[基于方法的 `@ServerFilter`]，不再实现 https://docs.micronaut.io/latest/guide/#httpServerFilter[`HttpServerFilter`]。

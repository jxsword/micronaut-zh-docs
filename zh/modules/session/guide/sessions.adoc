Micronaut 提供了本模块（灵感来自 https://projects.spring.io/spring-session/[Spring Session]）以支持这一能力，当前有两种实现：

* 内存会话——若计划运行多个实例，应将其与粘性会话代理结合使用。
* Redis 会话——此时 https://redis.io[Redis] 存储会话，并使用非阻塞 I/O 读写 Redis 中的会话。

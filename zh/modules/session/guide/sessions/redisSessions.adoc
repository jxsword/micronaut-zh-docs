要在 Redis 中存储 api:session.Session[] 实例，请使用 https://micronaut-projects.github.io/micronaut-redis/latest/guide/#sessions[Micronaut Redis] 模块，其中包含详细说明。

要快速上手 Redis 会话，您的构建中还需有 `redis-lettuce` 依赖：

dependency:micronaut-session[groupId=io.micronaut.session]

dependency:micronaut-redis-lettuce[groupId=io.micronaut.redis]

并通过应用配置文件中的配置启用 Redis 会话：

.启用 Redis 会话
[configuration]
----
redis:
  uri: redis://localhost:6379
micronaut:
  session:
    http:
      redis:
        enabled: true
----

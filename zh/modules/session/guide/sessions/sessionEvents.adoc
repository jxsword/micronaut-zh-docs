您可以注册 api:context.event.ApplicationEventListener[] bean，监听 pkg:session.event[] 包中与会话相关的事件。

下表汇总了这些事件：

.会话事件
|===
|类型|描述

|api:session.event.SessionCreatedEvent[]
|api:session.Session[] 创建时触发

|api:session.event.SessionDeletedEvent[]
|api:session.Session[] 被删除时触发

|api:session.event.SessionExpiredEvent[]
|api:session.Session[] 过期时触发

|api:session.event.SessionDestroyedEvent[]
|`SessionDeletedEvent` 与 `SessionExpiredEvent` 的共同父事件

|===

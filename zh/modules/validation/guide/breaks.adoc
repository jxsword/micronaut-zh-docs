本节记录 Micronaut Validation 各版本之间的破坏性变更：

=== Micronaut Validation 5.0.0 的破坏性变更

- api:validation.validator.DefaultValidator[] 的 `requireNonNull(String, T)` 与 `requireNonEmpty(String, String)` 方法此前已标记废弃，不再作为公共 API 暴露。

- api:validation.validator.constraints.ConstraintValidator[]（约束校验器）的 `getMessageTemplate())` 与 `requireNonEmpty(String, String)` 方法此前已废弃，现已移除。它们未被使用，且无替代品。

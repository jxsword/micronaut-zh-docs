要校验数据类（data class），例如 POJO（常用于 JSON 交换），类必须标注 {coreDocsUrl}core/annotation/Introspected[@Introspected]（参见 link:https://docs.micronaut.io/latest/guide/#introspection[Micronaut 指南内省一节]）；如果类是外部的，则需通过 `@Introspected` 注解导入。

.POJO 校验示例
snippet::io.micronaut.docs.validation.Person[tags="class"]

TIP: {coreDocsUrl}core/annotation/Introspected[@Introspected] 注解可用作元注解；`@jakarta.persistence.Entity` 等常见注解会被当作 `@Introspected` 处理

上例定义了一个 `Person` 类，其中两个属性（`name` 与 `age`）施加了约束。注意：Java 中注解可标注在字段或 getter 上；Kotlin data class 的注解应作用于字段；Python 中约束通过 `typing.Annotated` 声明在 `dataclass` 的属性上。

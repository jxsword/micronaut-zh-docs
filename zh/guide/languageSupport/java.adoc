对于 Java，Micronaut 框架使用 api:annotation.processing.BeanDefinitionInjectProcessor[] 注解处理器在编译期处理类并生成 api:inject.BeanDefinition[] 类。

这样做的主要优势在于，您只需在编译期付出少量代价，而在运行时 Micronaut 框架基本不使用反射、速度快且内存消耗极少。

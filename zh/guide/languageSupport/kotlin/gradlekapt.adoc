要在 Kapt 中启用 Gradle 增量注解处理，必须把 <<incrementalannotationgradle,Gradle 增量注解处理>> 一节指定的参数传给 Kapt。

以下示例演示如何为您在 `com.example` 与 `io.example` 包下定义的注解启用并配置增量注解处理：

.在 Kapt 中启用增量注解处理
[source,kotlin]
----
kapt {
    arguments {
        arg("micronaut.processing.incremental", true)
        arg("micronaut.processing.annotations", "com.example.*,io.example.*")
    }
}
----

WARNING: 如果您未为自定义注解启用处理，它们将被 Micronaut 忽略，这可能会破坏您的应用。

Micronaut 框架支持从 Reactor 上下文到协程上下文的上下文传播。要启用该传播，您需要包含以下依赖：

dependency:org.jetbrains.kotlinx:kotlinx-coroutines-reactor[]

有关如何使用该库的更详细信息，请参阅官方 link:https://kotlin.github.io/kotlinx.coroutines/kotlinx-coroutines-reactor/kotlinx.coroutines.reactor/-reactor-context/index.html[文档]。

NOTE: 自 Micronaut 框架 4 起，我们建议使用最新的 <<contextPropagation,上下文传播 API>>。api:core.propagation.ThreadPropagatedContextElement[] 的设计灵感来自 Kotlin 协程传播 API 元素 `kotlinx.coroutines.ThreadContextElement`，并通过恢复线程本地变量（thread locals）实现类似行为。

[[moduleScripts]]
Python 模块可以直接在模块层声明 Micronaut 注解。注解会成为生成的脚本类上的元数据，而模块层函数会成为该类上的方法。

例如，无类控制器无需定义 Python 类即可声明其路由前缀：

snippet::example.module_routes[tags="module-controller", indent=0, title="Module-level controller annotation"]

只有当调用的目标解析为 Micronaut 或 Python 自定义注解时，顶层调用才会被视为注解。普通模块调用仍是普通 Python 代码。

显式控制器注解优先于为包含 HTTP 路由的模块自动添加的隐式控制器注解。显式作用域注解同样优先于未加作用域的路由模块所使用的自动 `ContextPooled` 作用域。

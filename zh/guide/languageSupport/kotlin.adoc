TIP: Micronaut 框架的 <<cli,命令行界面>> 为 Kotlin 提供了特别支持。要创建 Kotlin 应用，请使用 `kotlin` lang 选项。例如：

[source,bash]
.创建 Micronaut Kotlin 应用
----
$ mn create-app hello-world --lang kotlin
----

自 4.0 版本起，Micronaut 框架通过 https://kotlinlang.org/docs/reference/kapt.html[Kapt] 或 https://kotlinlang.org/docs/ksp-overview.html[Kotlin Symbol Processing API] 提供 Kotlin 支持。

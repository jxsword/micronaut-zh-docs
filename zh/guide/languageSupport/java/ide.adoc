您可以使用任何 IDE 来开发 Micronaut 应用，只要您依靠所配置的构建工具（Gradle 或 Maven）来构建应用。

不过，目前只有 https://www.jetbrains.com/idea[IntelliJ IDEA] 或 Eclipse 4.9 及以上版本支持在 IDE 内运行测试。

有关如何配置 IntelliJ 和 Eclipse 的更多信息，请参阅快速开始中的 <<ideSetup,IDE 配置>> 一节。

默认情况下，在 Java 中，方法参数的参数名数据在编译时不会被保留。如果您没有显式定义参数名，并且依赖的是已编译的外部 JAR，这对 Micronaut 框架来说可能是个问题。

请看这个接口：

.客户端接口
[source,java]
----
interface HelloOperations {
    @Get("/hello/{name}")
    String hello(String name);
}
----

在编译期，参数名 `name` 会丢失，之后在针对其编译或通过反射读取时会变为 `arg0`。为避免此问题，您有两种选择。您可以显式声明参数名：

.客户端接口
[source,java]
----
interface HelloOperations {
    @Get("/hello/{name}")
    String hello(@QueryValue("name") String name);
}
----

或者，建议您在编译所有字节码时向 `javac` 传递 `-parameters` 标志。请参阅 https://docs.oracle.com/javase/tutorial/reflect/member/methodparameterreflection.html[Obtaining Names of Method Parameters]。例如在 `build.gradle` 中：

.build.gradle
[source,groovy]
----
compileJava.options.compilerArgs += '-parameters'
----

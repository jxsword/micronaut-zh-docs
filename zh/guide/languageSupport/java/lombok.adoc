https://projectlombok.org[Project Lombok] 是一个流行的 Java 库，它通过注解处理器为 Java 语言添加许多有用的 AST 变换。

由于 Micronaut 框架和 Lombok 都使用注解处理器，因此在配置 Lombok 时必须特别注意，确保 Lombok 处理器在 Micronaut 处理器*之前*运行。

如果您使用 Gradle，请添加以下依赖：

.在 Gradle 中配置 Lombok
[source,groovy]
----
compileOnly 'org.projectlombok:lombok:1.18.24'
annotationProcessor "org.projectlombok:lombok:1.18.24"
...
// Micronaut processor defined after Lombok
annotationProcessor "io.micronaut:micronaut-inject-java"
----

如果使用 Maven：

.在 Maven 中配置 Lombok
[source,xml]
----
<dependencies>
  <dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.24</version>
    <scope>provided</scope>
  </dependency>
</dependencies>
...
<annotationProcessorPaths combine.self="override">
  <path>
    <!-- must precede micronaut-inject-java -->
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.24</version>
  </path>
  <path>
    <groupId>io.micronaut</groupId>
    <artifactId>micronaut-inject-java</artifactId>
    <version>${micronaut.version}</version>
  </path>
  <path>
    <groupId>io.micronaut.validation</groupId>
    <artifactId>micronaut-validation-processor</artifactId>
    <version>${micronaut.version}</version>
  </path>
</annotationProcessorPaths>
----

NOTE: 在两种情况下（Gradle 和 Maven），Micronaut 处理器都必须配置在 Lombok 处理器之后。调换所声明依赖的顺序将无法工作。

为了帮助您轻松了解 Micronaut 在启动时正在做什么、某个特定的 bean 何时被创建，Micronaut 提供了依赖注入追踪（dependency injection tracing）功能，可以通过多种方式激活，其中包括 api:context.ApplicationContextBuilder[] API。

激活注入追踪模式的最简单方式是使用环境变量。例如，如果您在本地运行应用程序，可以执行：

.启用注入追踪模式
[source,bash]
----
MICRONAUT_INJECT_TRACE=.+ ./gradlew run
----

对于 Maven 则为：

.启用注入追踪模式
[source,bash]
----
MICRONAUT_INJECT_TRACE=.+ ./mvnw mn:run
----

追踪模式将输出诸如以下的有用信息：

* 应用程序的配置 profile
* 适用的配置及其来源
* 被创建的 bean、创建位置以及创建所耗费的时间

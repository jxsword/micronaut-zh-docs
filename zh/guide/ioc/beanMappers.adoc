自 4.1.x 起，ann:context.annotation.Mapper[] 注解可用于任何抽象方法，以自动创建一种类型与另一种类型之间的映射。自 4.8.x 起，该注解还可用于合并 bean。

受 https://mapstruct.org[Map Struct] 等库中类似功能的启发，`Mapper` 使用 Micronaut 框架内置的 <<introspection, Bean 内省>> 与 <<evaluatedExpressions, 表达式>> 特性，它们本身就是无反射的。

NOTE: 对于映射，源类型和目标类型都需要 <<introspection, 被内省>>。

=== @Mapping 示例

每个抽象方法可以定义单个 ann:context.annotation.Mapper[@Mapper] 注解，或定义一个或多个 ann:context.annotation.Mapper.Mapping[@Mapping] 注解来指定属性如何映射到目标类型。

snippet::io.micronaut.docs.ioc.mappers.ProductMappers[tags="class"]

`from` 成员可用于定义源类型上的属性名，或定义一个 <<evaluatedExpressions, 表达式>>——从方法实参读取值并按您选择的任意方式转换它们，包括调用实例的其他方法。

NOTE: 只有当需要应用转换才能成功完成映射时，才需要 `@Mapping` 定义。其他属性将自动映射和转换。

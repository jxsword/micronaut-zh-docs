与 JDK 的 link:{jdkapi}/java.desktop/java/beans/Introspector.html[Introspector] 不同，并非每个类都自动可用于内省。要使一个类可用于内省，您至少必须在构建中启用 Micronaut 的注解处理器（Java 和 Kotlin 使用 `micronaut-inject-java`，Groovy 使用 `micronaut-inject-groovy`），并确保对 `micronaut-core` 存在运行时依赖。

dependency::micronaut-inject-java[scope="annotationProcessor"]

NOTE: 对于 Kotlin，请在 `kapt` 作用域中添加 `micronaut-inject-java` 依赖；对于 Groovy，请在 `compileOnly` 作用域中添加 `micronaut-inject-groovy`。

dependency::micronaut-core[scope="runtimeOnly"]

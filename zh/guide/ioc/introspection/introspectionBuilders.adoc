如果某个类型只能通过构建器（builder）模式构造，您可以使用 ann:core.annotation.Introspected[] 注解的 `builder` 成员生成动态构建器。例如给定以下类：

snippet::io.micronaut.docs.ioc.builders.Person[tags="class"]

您可以使用 api:core.beans.BeanIntrospection[] API 的 `builder()` 方法构造实例：

snippet::io.micronaut.docs.ioc.builders.IntrospectionBuilderSpec[tags="builder", indent=0]

TIP: 无论该类型是否使用构建器，`builder()` 方法都能工作，并可作为对象构造的通用抽象。但请注意，与通过 `instantiate()` 方法直接实例化相比有轻微的性能开销，因此如果需要优化的代码路径，可以先检查 `hasBuilder()` 方法。

NOTE: 内省构建器不适用于 https://groovy-lang.org/metaprogramming.html#xform-Builder[Groovy `@Builder` AST]。

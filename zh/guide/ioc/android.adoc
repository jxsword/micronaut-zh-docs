由于 Micronaut 依赖注入基于注解处理器、不依赖反射，因此在使用 Android 插件 3.0.0 或更高版本时，它可以在 Android 上使用。

这让您可以在 Android 客户端与服务器实现中使用同一个应用框架。

== 配置 Android 构建

要开始使用，请使用 `annotationProcessor` 依赖配置将 Micronaut 注解处理器加入处理器类路径。

请在 Android 构建配置的 `annotationProcessor` 与 `compileOnly` 两个作用域中都加入 Micronaut `micronaut-inject-java` 依赖：

.Android build.gradle 示例
[source,groovy,subs="attributes"]
----
dependencies {
    ...
    annotationProcessor "io.micronaut:micronaut-inject-java:{version}"
    compileOnly "io.micronaut:micronaut-inject-java:{version}"
    ...
}
----

如果构建中使用了 `lint`，可能还需要禁用无效包检查，因为 Android 内置了一个硬编码检查，除非使用 Dagger，否则会把 `jakarta.inject` 包视为无效：

.在 build.gradle 中配置 lint
[source,groovy]
----
android {
    ...
    lintOptions {
        lintOptions { warning 'InvalidPackage' }
    }
}
----

关于 https://developer.android.com/studio/build/gradle-plugin-3-0-0-migration.html#annotationProcessor_config[配置注解处理器] 的更多信息，请参阅 Android 文档。

NOTE: Micronaut `inject-java` 依赖使用了 https://developer.android.com/studio/write/java8-support.html[Android Java 8 支持] 特性。

== 启用依赖注入

正确配置类路径后，下一步是启动 link:{api}/io/micronaut/context/ApplicationContext.html[ApplicationContext]。

下面的示例演示了为此创建 https://developer.android.com/reference/android/app/Application.html[android.app.Application] 的子类：

.Android Application 类示例
[source, java]
----
import android.app.Activity;
import android.app.Application;
import android.os.Bundle;

import io.micronaut.context.ApplicationContext;
import io.micronaut.context.env.Environment;

public class BaseApplication extends Application { // <1>

    private ApplicationContext ctx;

    @Override
    public void onCreate() {
        super.onCreate();
        ctx = ApplicationContext.run(MainActivity.class, Environment.ANDROID); // <2>
        registerActivityLifecycleCallbacks(new ActivityLifecycleCallbacks() { // <3>
            @Override
            public void onActivityCreated(Activity activity, Bundle bundle) {
                ctx.inject(activity);
            }
            ... // shortened for brevity; it is not necessary to implement other methods
        });
    }
}
----

<1> 继承 `android.app.Application` 类
<2> 以 `ANDROID` 环境运行 `ApplicationContext`
<3> 注册一个 `ActivityLifecycleCallbacks` 实例，允许对 Android `Activity` 实例进行依赖注入

link:{api}/io/micronaut/context/BeanContext.html[BeanContext] 是承载您所有 bean 定义的容器对象（它同时实现了 link:{api}/io/micronaut/context/BeanDefinitionRegistry.html[BeanDefinitionRegistry]）。

它也是 Micronaut 的初始化起点。不过一般来说，您无需直接与 `BeanContext` API 交互，只需使用 `jakarta.inject` 注解以及 link:{api}/io/micronaut/context/annotation/package-summary.html[io.micronaut.context.annotation] 包中的注解即可满足依赖注入需求。

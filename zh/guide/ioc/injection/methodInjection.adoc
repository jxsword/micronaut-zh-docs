可以通过用 `jakarta.inject.Inject` 注解方法来注入方法。对于方法的每个参数，Micronaut 都会尝试将其解析为一个 bean。如果任一参数无法解析，将抛出 api:context.exceptions.NoSuchBeanException[]。

--
WARNING: 如果方法是 `private` 作用域或不可访问，则该方法将通过 Java 反射 API 注入，不推荐这样做。
--

如果需要构造后初始化器，方法注入可能很有用，但一般应尽量避免使用，在可能的情况下优先选择构造器注入。

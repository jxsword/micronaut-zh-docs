[[upgrading]]
=== 在 Micronaut Framework 版本之间升级

查阅 https://micronaut-projects.github.io/micronaut-upgrade/snapshot/[Micronaut Upgrade] 文档，帮助您升级 Micronaut 应用程序。

要了解新特性，请查看您所关注的每个模块的 GitHub Release 说明，其中包含按类型划分的全部变更摘要。

=== 破坏性变更

请查阅 <<breaks,破坏性变更>> 一节，并更新受影响的应用程序代码。

所有代码生成命令都会遵循 `micronaut-cli.yml` 中写入的值。例如，假设有如下 `micronaut-cli.yml` 文件。

.micronaut-cli.yml
[source,yaml]
----
defaultPackage: example
---
testFramework: spock
sourceLanguage: java
----

使用上述设置时，`create-bean` 命令（默认）会在 `example` 包中生成一个 Java 类及关联的 Spock 测试。命令接受实参，这些默认值可以按命令单独覆盖。

== 基础命令

这些命令在 micronaut 项目的上下文中始终可用。

=== Create-Bean

.Create-Bean 的 flag
|===
|flag|描述|示例

|`-l`, `--lang`
|bean 类使用的语言
|`--lang groovy`

|`-f`, `--force`
|是否覆盖现有文件
|`--force`

|
|===

`create-bean` 命令生成一个简单的 {jakartaapi}/jakarta/inject/Singleton.html[Singleton] 类。它不会创建关联测试。

[source,bash]
----
$ mn create-bean EmailService
| Rendered template Bean.java to destination src/main/java/example/EmailService.java
----

== HTTP 相关命令

=== Create-Controller

.Create-Controller 的 flag
|===
|flag|描述|示例

|`-l`, `--lang`
|控制器使用的语言
|`--lang groovy`

|`-f`, `--force`
|是否覆盖现有文件
|`--force`

|
|===

`create-controller` 命令生成一个 link:{api}/io/micronaut/http/annotation/Controller.html[Controller] 类。生成类名时遵循 `*Controller` 约定。它会创建一个关联测试，该测试运行应用并实例化一个 HTTP 客户端，可以向控制器发起请求。

[source,bash]
----
$ mn create-controller Book
| Rendered template Controller.java to destination src/main/java/example/BookController.java
| Rendered template ControllerTest.java to destination src/test/java/example/BookControllerTest.java
----

== CLI 项目命令

=== Create-Command

.Create-Command 的 flag
|===
|flag|描述|示例

|`-l`, `--lang`
|命令使用的语言
|`--lang groovy`

|`-f`, `--force`
|是否覆盖现有文件
|`--force`

|
|===

`create-command` 命令生成一个可按 https://picocli.info[picocli] link:https://picocli.info/apidocs/picocli/CommandLine.Command.html[Command] 执行的独立应用。生成类名时遵循 `*Command` 约定。它会创建一个关联测试，该测试运行应用并验证命令行选项已被设置。

[source,bash]
----
$ mn create-command print
| Rendered template Command.java to destination src/main/java/example/PrintCommand.java
| Rendered template CommandTest.java to destination src/test/java/example/PrintCommandTest.java
----

此列表只是 Micronaut CLI 中代码生成命令的一小部分。要查看 CLI 在不同上下文中可用的全部命令（以及在何种情况下适用），请查看 https://github.com/micronaut-projects/micronaut-starter[micronaut-starter] 项目，找到继承 `CodeGenCommand` 的类。`applies` 方法决定命令是否可用。

重载（或「热加载」）指框架在检测到源文件变更时重新初始化类（及应用的各部分）。

由于 Micronaut 优先考虑启动时间，且大多数 Micronaut 应用可以在数秒内启动，通过在变更时重启应用（例如在 IDE 中运行一个测试类）通常就能获得高效的工作流。

不过，若要让变更自动重载，Micronaut 支持自动重启以及使用第三方重载代理。

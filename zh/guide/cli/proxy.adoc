[[proxy]]
要将 CLI 配置为使用 HTTP 代理，需要两个步骤。配置选项可以通过 `MN_OPTS` 环境变量传给 CLI。

例如在 *nix 系统上：

[source,bash]
----
export MN_OPTS="-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=3128 -Dhttp.proxyUser=test -Dhttp.proxyPassword=test"
----

profile 依赖通过 HTTPS 解析，因此代理端口与主机用 `https.` 配置，而用户名与密码用 `http.` 指定。

Windows 系统可在 `My Computer/Advanced/Environment Variables` 下配置该环境变量。

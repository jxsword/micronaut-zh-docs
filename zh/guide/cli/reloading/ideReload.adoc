如果使用的是 Maven 这类不支持文件变更时自动重新编译的构建工具，您可以结合重载代理（按上述章节配置）用 IDE 重新编译类。

[[ideReload]]
=== IntelliJ

遗憾的是，IntelliJ 没有对运行中应用有效的自动重建选项。不过，您可以用 `CMD-F9` （Mac）或 `CTRL-F9` （Windows/Linux）触发项目的「重建」。

=== Eclipse

在 `Project` 菜单下，勾选 `Build Automatically` 选项。这样每当文件变更保存到磁盘时，都会触发项目的重新编译。

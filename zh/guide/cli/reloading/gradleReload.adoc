[[gradleReload]]
Gradle 支持 https://docs.gradle.org/current/userguide/command_line_interface.html#sec:continuous_build[持续构建（continuous builds）]，让您运行一个每当源文件变更就会重新执行的任务。要将其与重载代理（按上文所述配置）结合使用，请正常启动应用（带代理），然后在另一个终端以持续模式运行一个重新编译任务。

.运行应用
[source,bash]
----
$ ./gradlew run
----

.运行重新编译
[source,bash]
----
$ ./gradlew -t classes
----

每当源文件被修改时，`classes` 任务都会重新执行，让重载代理拾取变更。

link:{api}/io/micronaut/context/annotation/EachProperty.html[@EachProperty] 注解是驱动动态配置的好方式，但通常您希望将该配置注入到依赖它的另一个 bean 中。使用硬编码限定符注入单个实例并不是好的解决方案，因此 `@EachProperty` 通常与 link:{api}/io/micronaut/context/annotation/EachBean.html[@EachBean] 结合使用：

snippet::io.micronaut.docs.config.env.DataSourceFactory[tags="eachBean", indent=0, title="Using @EachBean"]

<1> 上面的示例定义了一个 link:{api}/io/micronaut/context/annotation/Factory.html[Factory] bean，用于创建 `javax.sql.DataSource` 实例。
<2> link:{api}/io/micronaut/context/annotation/EachBean.html[@EachBean] 注解表示将为上一节中定义的每个 `DataSourceConfiguration` 创建一个新的 `DataSource` bean。
<3> `DataSourceConfiguration` 实例作为方法参数注入，并用于驱动每个 `javax.sql.DataSource` 的配置

NOTE: `@EachBean` 要求父 bean 具有 `@Named` 限定符，因为该限定符会被 `@EachBean` 创建的每个 bean 继承。

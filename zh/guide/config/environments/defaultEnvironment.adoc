Micronaut 框架支持一个或多个默认环境（default environment）的概念。
默认环境只有在未显式指定或推断出其他环境时才会被应用。
可以通过应用上下文构建器 `Micronaut.build().environments(...)`、`micronaut.environments` 系统属性或 `MICRONAUT_ENVIRONMENTS` 环境变量显式指定环境。
还可以通过推断来自动应用适合云部署的环境。
如果通过上述任一方式找到了环境，则 *不会* 应用默认环境。

要设置默认环境，请包含一个实现 api:context.ApplicationContextConfigurer[] 并以 api:context.annotation.ContextConfigurer[] 注解标注的公共静态类：

[source,java]
----
public class Application {

    @ContextConfigurer
    public static class DefaultEnvironmentConfigurer implements ApplicationContextConfigurer {
        @Override
        public void configure(@NonNull ApplicationContextBuilder builder) {
            builder.defaultEnvironments(defaultEnvironment);
        }
    }

    public static void main(String[] args) {
        Micronaut.run(Application.class, args);
    }
}
----

NOTE: 过去我们推荐使用 `Micronaut.defaultEnvironments("dev")`，但这会导致 AOT（Ahead-of-Time）编译器无法检测到默认环境。

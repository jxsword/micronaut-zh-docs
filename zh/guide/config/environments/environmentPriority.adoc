Micronaut 框架根据指定的环境加载属性源（property source）；若同一个属性键存在于多个特定于环境的属性源中，则环境顺序决定使用哪个值。

Micronaut 框架使用以下层次结构处理环境（优先级从低到高）：

* 推断的环境
* 来自 `micronaut.environments` 系统属性的环境
* 来自 `MICRONAUT_ENVIRONMENTS` 环境变量的环境
* 通过应用上下文构建器显式指定的环境
+
NOTE: 这同样适用于 `@MicronautTest(environments = ...)`

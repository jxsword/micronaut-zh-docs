将 `micronaut.env.deduction` 系统属性或 `MICRONAUT_ENV_DEDUCTION` 环境变量设置为 `false`，即可禁用环境的自动检测。这会阻止 Micronaut 框架检测当前环境，但仍会使用如上所示显式提供的环境。

.通过系统属性禁用环境检测
[source,bash]
----
$  java -Dmicronaut.env.deduction=false -jar myapp.jar
----

另外，也可以在设置应用时，使用 api:context.ApplicationContextBuilder[] 的 `deduceEnvironment` 方法禁用环境推断。

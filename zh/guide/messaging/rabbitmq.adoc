https://www.rabbitmq.com[RabbitMQ] 是部署最广泛的开源消息代理（message broker）。

Micronaut 框架为定义 RabbitMQ 发布者与消费者提供专门支持。基于 RabbitMQ 构建的 Micronaut 应用可以在有或没有 HTTP 服务器的情况下部署。

借助 Micronaut 框架高效的编译期 AOP，使用 RabbitMQ 从未如此简单。同时还新增了对通过响应式流实现发布者确认（publisher confirms）与 RPC 的支持。

有关如何使用 Micronaut 构建 RabbitMQ 应用的更多信息，请参阅 https://micronaut-projects.github.io/micronaut-rabbitmq/latest/guide[Micronaut RabbitMQ] 文档。

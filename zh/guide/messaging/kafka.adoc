https://kafka.apache.org[Apache Kafka] 是一个分布式流处理平台，除流处理和实时数据处理外，还可用于一系列消息传递需求。

Micronaut 框架为定义 Kafka `Producer` 与 `Consumer` 实例提供专门支持。基于 Kafka 构建的 Micronaut 应用可以在有或没有 HTTP 服务器的情况下部署。

借助 Micronaut 高效的编译期 AOP 与云原生特性，编写占用资源极少的高效 Kafka 消费者应用轻而易举。

有关如何使用 Micronaut 构建 Kafka 应用的更多信息，请参阅 https://micronaut-projects.github.io/micronaut-kafka/latest/guide[Micronaut Kafka] 文档。

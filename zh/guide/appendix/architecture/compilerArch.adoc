[[compilerArch]]
Micronaut 编译器是对现有语言编译器的一组扩展：

* Java - Java 代码使用 link:{jdkapi}/java.compiler/javax/annotation/processing/package-summary.html[Java 注解处理（APT）API]。
* Kotlin - Kotlin 代码使用 https://kotlinlang.org/docs/kapt.html[KAPT] 或 https://kotlinlang.org/docs/ksp-overview.html[KSP]。
* Groovy - Groovy 代码使用 Groovy 的 https://docs.groovy-lang.org/latest/html/api/org/codehaus/groovy/transform/ASTTransformation.html[AST 变换] 参与编译。

为保持本文档简洁，后续章节将以与 Java 编译器的交互为例进行描述。

Micronaut 编译器访问最终用户代码，并生成与用户代码位于同一包结构中的附加字节码。

用户源码的 AST 通过 api:inject.visitor.TypeElementVisitor[]（类型元素访问者）的实现来访问，这些实现经 link:{jdkapi}/java.base/java/util/ServiceLoader.html[标准 Java 服务加载器机制] 加载。

每个 api:inject.visitor.TypeElementVisitor[] 实现都可以重写一个或多个 `visit*` 方法，这些方法接收 api:inject.ast.Element[] 的实例。

link:../api/io/micronaut/inject/ast/package-summary.html[Element API] 为 AST 以及为给定元素（类、方法、字段等）计算 api:core.annotation.AnnotationMetadata[] 提供了语言中立 abstraction。

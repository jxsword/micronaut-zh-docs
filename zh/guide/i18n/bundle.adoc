资源包（resource bundle）是一个包含特定语言区域数据的 Java .properties 文件。

给定如下资源包：

[source, properties]
.src/main/resources/io/micronaut/docs/i18n/messages_en.properties
----
include::test-suite/src/test/resources/io/micronaut/docs/i18n/messages_en.properties[]
----

[source, properties]
.src/main/resources/io/micronaut/docs/i18n/messages_es.properties
----
include::test-suite/src/test/resources/io/micronaut/docs/i18n/messages_es.properties[]
----

您可以使用 api:context.i18n.ResourceBundleMessageSource[]——一个便于访问 link:{jdkapi}/java.base/java/util/ResourceBundle.html[资源包] 并提供缓存功能的 api:context.MessageSource[] 实现——来访问上述消息。

WARNING: 请不要在每次检索消息时都实例化一个新的 `ResourceBundleMessageSource`。请只实例化一次，例如在工厂中实例化。

snippet::io.micronaut.docs.i18n.MessageSourceFactory[tags="imports,clazz",indent=0,title="MessageSource Factory Example"]

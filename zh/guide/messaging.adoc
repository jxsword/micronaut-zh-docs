过去，在单体应用中，监听来自消息系统的消息的消息监听器通常内嵌在同一个应用单元里。

在微服务架构中，常见做法是由 RabbitMQ 或 Kafka 等消息系统驱动的各个微服务应用相互独立。

事实上，消息驱动（message-driven）的微服务甚至可能不提供 HTTP 端点或 HTTP 服务器（尽管从健康检查和可观测性的角度来看，HTTP 端点很有价值）。

日志级别可以通过配置文件（例如 `application.yml`）（以及环境变量）中定义的属性进行配置，这些属性须以 `logger.levels` 为前缀：

[configuration]
----
logger:
  levels:
    foo.bar: ERROR
----

通过设置环境变量 `LOGGER_LEVELS_FOO_BAR` 也可以达到相同的配置效果。请注意，目前无法为 `foo.barBaz` 这类非常规前缀设置日志级别。

==== 自定义 Logback XML 配置

[configuration]
----
logger:
  config: /foo/custom-logback.xml
----

您还可以通过 `logger.config` 设置要使用的自定义 Logback XML 配置文件。
该文件会先在类路径中查找，然后再在文件系统中查找。

==== 通过属性禁用 logger

要禁用某个 logger，您需要将其级别设置为 `OFF`：

[configuration]
----
logger:
  levels:
    io.verbose.logger.who.CriedWolf: OFF
----
- 这将禁用 `io.verbose.logger.who.CriedWolf` 的全部日志记录


请注意，通过配置控制日志级别的能力由 api:logging.LoggingSystem[] 接口控制。目前，Micronaut 框架仅包含一个允许为 Logback 库设置日志级别的实现。如果您使用其他库，则应提供一个实现该接口的 bean。

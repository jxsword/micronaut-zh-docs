要使用 logback 库，请在构建中添加以下依赖。

dependency:ch.qos.logback:logback-classic[gradleScope="implementation"]

NOTE: Logback 1.3.x+ 包含一项破坏性的二进制变更，可能导致其无法与 Micronaut 框架 3.8.x 一起工作。如果您正在使用 Logback 1.3.x+ 并且遇到问题，请降级到 Logback 1.2.x。

如果尚不存在，请在 resources 文件夹中放置一个 link:https://logback.qos.ch/manual/configuration.html[logback.xml] 文件，并根据需要修改其内容。例如：

.src/main/resources/logback.xml
[source,xml]
----
<configuration>

    <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>%cyan(%d{HH:mm:ss.SSS}) %gray([%thread]) %highlight(%-5level) %magenta(%logger{36}) - %msg%n
            </pattern>
        </encoder>
    </appender>

    <root level="info">
        <appender-ref ref="STDOUT"/>
    </root>

</configuration>
----

要更改特定类或包名的日志级别，您可以在配置节中添加这样的 logger 条目：

[source,xml]
----
<configuration>
    ...
    <logger name="io.micronaut.context" level="TRACE"/>
    ...
</configuration>
----

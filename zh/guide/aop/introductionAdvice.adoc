[[introductionAdvice]]
引入通知（Introduction Advice）与环绕通知的不同之处在于，它提供实现而不是装饰。

引入通知的示例包括 https://spring.io/projects/spring-data/[Spring Data]，它为您实现持久化逻辑。

Micronaut 的 api:http.client.annotation.Client[] 注解是引入通知的另一个示例，Micronaut 框架在编译期为您实现 HTTP 客户端接口。

实现引入通知的方式与实现环绕通知非常相似。

首先定义一个驱动引入通知的注解。举例来说，假设您希望实现一个通知，为接口中的每个方法返回存根值（stubbed value，测试框架中的常见需求）。请看以下 `@Stub` 注解：

snippet::io.micronaut.docs.aop.introduction.Stub[tags="imports,class", indent=0, title="Introduction Advice Annotation Example"]

<1> 引入通知以 api:aop.Introduction[] 注解标注
<2> 添加 api:context.annotation.Bean[] 注解，使所有标注了 `@Stub` 的类型成为 bean

前一示例中引用的 `StubIntroduction` 类必须实现 api:aop.MethodInterceptor[] 接口，与环绕通知一样。

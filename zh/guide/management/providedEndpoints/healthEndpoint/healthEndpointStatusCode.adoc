`endpoints.health.status.http-mapping` 设置控制每种健康状态返回的状态码。默认值见下表：

|===
|状态 | HTTP 状态码

|api:health.HealthStatus#UP[]
|api:http.HttpStatus#OK[] （200）

|api:health.HealthStatus#UNKNOWN[]
|api:http.HttpStatus#OK[] （200）

|api:health.HealthStatus#DOWN[]
|api:http.HttpStatus#SERVICE_UNAVAILABLE[] （503）

|===

您可以在配置文件（例如 `application.yml`）中提供自定义映射：

.自定义健康状态码
[configuration]
----
endpoints:
  health:
    status:
      http-mapping:
        DOWN: 200
----

上例即使 api:health.HealthStatus[] 为 api:health.HealthStatus#DOWN[] 时也返回 api:http.HttpStatus#OK[] （200）。

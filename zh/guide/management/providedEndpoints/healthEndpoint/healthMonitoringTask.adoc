使用 api:runtime.server.EmbeddedServer[] 时，可以通过以下应用配置启用一个在后台线程中更新 api:health.CurrentHealthStatus[] 的持续健康监视器：

[configuration]
----
micronaut:
  application:
    name: foo
  health:
    monitor:
      enabled: true
----
- 要启用监视器后台任务，两个配置属性都必须设置。

与 `DefaultHealthAggregator` 类似，它也会为健康指示器的状态与详情输出日志语句。为此请使用以下 logger 配置：

[source,xml]
----
<logger name="io.micronaut.management.health.monitor.HealthMonitorTask" level="trace" />
----

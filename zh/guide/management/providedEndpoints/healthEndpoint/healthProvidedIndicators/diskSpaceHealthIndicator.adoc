框架提供一个基于可用磁盘空间判定应用健康的健康指示器。磁盘空间健康指示器的配置可在 `endpoints.health.disk-space` 键下提供。

.磁盘空间指示器配置示例
[configuration]
----
endpoints:
  health:
    disk-space:
      enabled: Boolean
      path: String
      threshold: String | Long
----

- `path` 指定用于确定磁盘空间的路径
- `threshold` 指定最小可用空间

阈值可以提供为「10MB」或「200KB」这样的字符串，也可以是字节数。

threaddump 端点返回应用中运行线程的信息。

要执行 threaddump 端点，请向 /threaddump 发送 GET 请求。

== 配置

要配置 threaddump 端点，请通过 `endpoints.threaddump` 提供配置。

.Threaddump 端点配置示例
[configuration]
----
endpoints:
  threaddump:
    enabled: Boolean
    sensitive: Boolean
----

== 定制

线程转储端点委托给一个 link:{api}/io/micronaut/management/endpoint/threads/ThreadInfoMapper.html[ThreadInfoMapper])，它负责把 `java.lang.management.ThreadInfo` 对象转换为任何其他对象以供序列化。

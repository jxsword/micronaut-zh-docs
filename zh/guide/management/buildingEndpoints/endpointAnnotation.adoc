通过为类标注 link:{api}/io/micronaut/management/endpoint/annotation/Endpoint.html[Endpoint] 注解并提供（至少）一个端点 id，即可创建端点。

[source,java]
.FooEndpoint.java
----
@Endpoint("foo")
class FooEndpoint {
    ...
}
----

如果向注解提供单个 `String` 实参，它将被用作端点 id。

还可以向注解提供额外的（具名）实参。`@Endpoint` 的其他可用实参见下表：

.端点实参
|===
|实参|描述 |端点示例

|`String id`
|端点 id（或名称）
|`@Endpoint(id = "foo")`

|`String prefix`
|用于配置该端点的前缀（参见 <<endpointConfiguration,端点配置>>）
|`@Endpoint(prefix = "foo")`

|`boolean defaultEnabled`
|设置未配置时端点是否启用（参见 <<endpointConfiguration,端点配置>>）
|`@Endpoint(defaultEnabled = false)`

|`boolean defaultSensitive`
|设置未配置时端点是否敏感（参见 <<endpointConfiguration,端点配置>>）
|`@Endpoint(defaultSensitive = false)`

|===

[[languageSupport]]
Micronaut 框架支持任何实现了 link:{jdkapi}/java.compiler/javax/annotation/processing/package-summary.html[Java Annotation Processor] API 的 JVM 语言。

尽管 Groovy 不支持该 API，但已通过 AST 变换（AST transformations）为其构建了特殊支持。当前支持的语言列表为：Java、Groovy、Kotlin（通过 `kapt` 工具）和 Python。

NOTE: 从理论上讲，任何支持在编译期分析 AST 的语言都可以获得支持。pkg:inject.writer[] 包中包含一些语言中立的类，它们在编译期使用 ASM 工具构建 api:inject.BeanDefinition[] 类。

要使用基于 https://netty.io[Netty] 的实现，请向构建中添加以下依赖：

dependency:micronaut-http-client[]

== 在 SSL 配置中禁用主机名验证

在测试或开发环境中可能需要禁用主机名验证。

要在测试类路径中禁用主机名验证，您可以在 `src/test/java` 中创建一个 <<replaces,bean 替换>>：

[source,java]
----
include::http-client/src/test/java/io/micronaut/http/client/netty/ssl/NettyClientSslBuilderReplacement.java[indent=0]
----
WARNING: 禁用主机名验证会使您的应用容易受到中间人（Man-in-the-Middle）攻击，因此应极为谨慎地执行，通常仅在开发/测试环境中进行。切勿在生产环境中，或在通过互联网进行远程调用的场景中禁用主机名验证。

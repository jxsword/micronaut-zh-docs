到目前为止的所有示例都使用了相同的 HTTP 方法，即 `GET`。api:http.HttpRequest[] 接口为所有不同的 HTTP 方法提供了工厂方法。下表汇总了它们：

.HttpRequest 工厂方法
|===
|方法 |说明|允许请求体

| api:http.HttpRequest.GET(java.lang.String)[]
| 构造 HTTP `GET` 请求
| `false`

| api:http.HttpRequest.OPTIONS(java.lang.String)[]
| 构造 HTTP `OPTIONS` 请求
| `false`

| api:http.HttpRequest.HEAD(java.lang.String)[]
| 构造 HTTP `HEAD` 请求
| `false`

| api:http.HttpRequest.POST(java.lang.String,T)[]
| 构造 HTTP `POST` 请求
| `true`

| api:http.HttpRequest.PUT(java.lang.String,T)[]
| 构造 HTTP `PUT` 请求
| `true`

| api:http.HttpRequest.PATCH(java.lang.String,T)[]
| 构造 HTTP `PATCH` 请求
| `true`

| api:http.HttpRequest.DELETE(java.lang.String)[]
| 构造 HTTP `DELETE` 请求
| `true`

|===

还存在一个 `create` 方法，可用于为任何 api:http.HttpMethod[] 类型构造请求。由于 `POST`、`PUT` 与 `PATCH` 方法需要请求体，因此需要第二个参数作为请求体对象。

== 发送 JSON

前面的示例发送纯文本。要发送 JSON，将要编码为 JSON 的对象（无论是 Map 还是 POJO）传入即可，只要 Jackson 能够编码它。

例如，您可以创建上一节中的 `Message` 并将其传给 `POST` 方法：

snippet::io.micronaut.docs.basics.HelloControllerSpec[tags="postpojo", indent=0, title="Sending a JSON body"]

<1> 创建 `Message` 实例并传给 `POST` 方法
<2> 同一个类解码响应

在上例中，以下 JSON 会作为请求体发送：

.产生的 JSON
[source,json]
----
{"text":"Hello John"}

可以使用 https://github.com/FasterXML/jackson-annotations[Jackson Annotations] 自定义 JSON。

== 使用 URI 模板

如果要将对象的某些属性包含在 URI 中，可以使用 URI 模板。

例如，假设您有一个具有 `title` 属性的 `Book` 类。您可以在 URI 模板中包含 `title`，然后从 `Book` 实例填充它。例如：

如果返回的 HTTP 响应状态码为 400 或更高，会创建 api:http.client.exceptions.HttpClientResponseException[]。该异常包含原始响应。异常如何抛出取决于方法的返回类型。

对于阻塞客户端，异常会被抛出，应由调用方捕获并处理。对于响应式客户端，异常作为错误通过发布者传递。

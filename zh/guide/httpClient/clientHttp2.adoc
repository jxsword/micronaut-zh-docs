默认情况下，Micronaut 的 HTTP 客户端配置为支持 HTTP 1.1。要启用 HTTP/2 支持，请在配置中设置支持的 HTTP 版本：

.在客户端中启用 HTTP/2
[configuration]
----
micronaut:
  http:
    client:
      http-version: 2.0
----

或者在注入客户端时指定要使用的 HTTP 版本：

.注入 HTTP/2 客户端
[source,java]
----
@Inject
@Client(httpVersion=HttpVersion.HTTP_2_0)
ReactorHttpClient client;
----

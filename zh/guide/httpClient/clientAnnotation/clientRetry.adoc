从故障中恢复对 HTTP 客户端至关重要，这正是 Micronaut 集成的 <<retry,重试通知>> 的用武之地。

NOTE: 自 Micronaut Framework 4.0 起，以 ann:http.client.annotation.Client[] 标注的声明式客户端默认不再调用 fallback。要恢复之前的行为，请添加以下依赖并为任何声明式客户端标注 ann:retry.annotation.Recoverable[]。

dependency::micronaut-retry[]

您可以在任何 ann:http.client.annotation.Client[] 接口上声明 ann:retry.annotation.Retryable[] 或 ann:retry.annotation.CircuitBreaker[] 注解，重试策略将被应用，例如：

自定义请求头值得特别一提，因为有多种方式可以实现。

== 通过配置填充请求头

ann:http.annotation.Header[] 注解可以声明在类型级别，并且是可重复的，因此可以通过注解元数据经由配置驱动发送的请求头。

下面的示例用于说明这一点：

snippet::io.micronaut.docs.annotation.headers.PetClient[tags="class", indent=0, title="Defining Headers via Configuration"]

上例在 `PetClient` 接口上定义了一个 ann:http.annotation.Header[] 注解，它使用属性占位符配置读取 `pet.client.id` 属性。

然后在配置文件（例如 `application.yml`）中设置以下内容来填充该值：

.配置请求头
[configuration]
----
pet:
  client:
    id: foo
----

或者，您也可以提供 `PET_CLIENT_ID` 环境变量，值将被填充。

== 使用客户端过滤器填充请求头

或者，要动态填充请求头，另一种选择是使用 <<clientFilter,客户端过滤器>>。

有关编写客户端过滤器的更多信息，请参阅指南的 <<clientFilter,客户端过滤器>> 一节。

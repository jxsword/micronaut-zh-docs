[[clientHttp3]]
自 Micronaut framework 4.x 起，基于 Netty 的 Micronaut HTTP 客户端可以配置为支持 HTTP/3。

与 HTTP/1.1 和 HTTP/2 使用的 TCP 不同，HTTP/3 运行在 UDP 上。如果客户端为 `alpn-modes` 属性配置了特殊的 `h3` 值，客户端将自动改用基于 UDP 的 HTTP/3 而不是基于 TCP 的 HTTP/1.1 或 HTTP/2。目前，如果服务器不支持 HTTP/3，客户端无法回退到 TCP。

.在客户端中启用 HTTP/3
[configuration]
----
micronaut:
  http:
    client:
      alpn-modes: [h3]
----

此外，类路径上需要有 Netty 的 HTTP/3 编解码器：

dependency:micronaut-http-netty-http3[]

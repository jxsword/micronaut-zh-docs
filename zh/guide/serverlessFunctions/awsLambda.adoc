对 AWS Lambda 的支持在 https://micronaut-projects.github.io/micronaut-aws/latest/guide/#whatsNew[Micronaut AWS] 子项目中实现。

==== 基于 AWS Lambda 的简单函数

您可以使用 Micronaut 框架编写直接实现 AWS Lambda SDK API 的 AWS 请求处理器（Request Handler）。更多信息请参阅 https://micronaut-projects.github.io/micronaut-aws/latest/guide/#requestHandlers[Micronaut Request Handlers] 文档。

[TIP]
.使用 CLI
====
要创建 AWS Lambda 函数：
----
$ mn create-function-app my-app --features aws-lambda
----
或使用 Micronaut Launch：
----
$ curl https://launch.micronaut.io/create/function/example\?features\=aws-lambda -o example.zip
$ unzip example.zip -d example
----
====

==== 基于 AWS Lambda 的 HTTP 函数

您可以借助 Micronaut 对 AWS API Gateway 的支持，部署使用 ann:http.annotation.Controller[] 等注解的常规 Micronaut 应用。更多信息请参阅 https://micronaut-projects.github.io/micronaut-aws/latest/guide/#applicationtyperuntimedependencies[AWS 应用类型、Lambda 运行时与依赖] 文档。

[TIP]
.使用 CLI
====
要创建 AWS API Gateway Proxy 应用：
----
$ mn create-app my-app --features aws-lambda
----
或使用 Micronaut Launch：
----
$ curl https://launch.micronaut.io/example.zip\?features\=aws-lambda -o example.zip
$ unzip example.zip -d example
----

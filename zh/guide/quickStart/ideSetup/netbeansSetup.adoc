Apache NetBeans 开箱即可打开 Maven 与 Gradle 项目。

请确保在 `Tools -> Plugins -> Installed` 中启用 **Java Web and EE** 功能，
以获得对 Micronaut 的额外支持，例如配置元素与数据元素的代码补全。

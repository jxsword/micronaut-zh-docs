[[buildCLI]]
Micronaut CLI 是创建 Micronaut 应用程序的一种可选但便捷的方式。在 Unix 系统上安装 Micronaut CLI 的最佳方式是使用 https://sdkman.io/[SDKMAN]，它极大地简化了多个 Micronaut 版本的安装与管理。

要查看所有可用的安装方式，请查阅 https://micronaut-projects.github.io/micronaut-starter/latest/guide/#installation[Micronaut Starter 文档]。

要部署 Micronaut 应用程序，请运行 `./gradlew assemble` 或 `./mvnw package` 创建可执行 JAR 文件。

构建出的 JAR 文件随后可用 `java -jar` 执行。例如：

[source,bash]
----
$ java -jar build/libs/hello-world-0.1-all.jar
----

（使用 Gradle 构建时），或者：

[source,bash]
----
$ java -jar target/hello-world.jar
----

（使用 Maven 构建时）。

可执行 JAR 可以在本地运行，也可以部署到支持可执行 JAR 的虚拟机或托管云服务。

要将分层应用程序发布到 Docker 容器仓库，请在 Gradle 的 `build.gradle` 中配置 Docker 镜像名称：

[source,groovy]
----
dockerBuild {
    images = ["[REPO_URL]/[NAMESPACE]/my-image:$project.version"]
}
----

然后使用 `dockerPush` 推送已构建的应用程序镜像：

[source,bash]
----
$ ./gradlew dockerPush
----

对于 Maven，请在 POM 中定义以下插件：

[source,xml]
----
<plugin>
  <groupId>com.google.cloud.tools</groupId>
  <artifactId>jib-maven-plugin</artifactId>
  <configuration>
    <to>
      <image>docker.io/my-company/my-image:${project.version}</image>
    </to>
  </configuration>
</plugin>
----

然后调用 `deploy` 生命周期阶段，并将打包类型指定为 `docker` 或 `docker-native`：

[source,bash]
----
$ ./mvnw deploy -Dpackaging=docker
----

[[httpClient]]
微服务之间的客户端通信是任何微服务架构的关键组成部分。有鉴于此，Micronaut 框架包含一个既有低层 API 又有高层 AOP 驱动 API 的 HTTP 客户端。

TIP: 无论您是否选择使用 Micronaut 的 HTTP 服务器，您都可能希望在应用中使用 Micronaut HTTP 客户端，因为它是一个功能丰富的客户端实现。

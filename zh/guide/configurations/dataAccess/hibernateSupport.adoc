[[hibernateSupport]]
==== 设置 Hibernate/JPA EntityManager

[TIP]
.使用 CLI
====
如果您使用 Micronaut CLI 创建项目，请提供 `hibernate-jpa` feature 以在项目中包含 Hibernate JPA 配置：
----
$ mn create-app my-app --features hibernate-jpa
----
====

Micronaut 框架支持配置构建于 <<sqlSupport,SQL 数据源支持>> 之上的 https://hibernate.org[Hibernate] / JPA `EntityManager`。

一旦您已 <<sqlSupport,配置一个或多个 DataSource>> 以使用 Hibernate，请将 `hibernate-jpa` 依赖添加到您的构建中：

dependency:micronaut-hibernate-jpa[groupId="io.micronaut.sql"]

更多信息请参阅 https://github.com/micronaut-projects/micronaut-sql[Micronaut SQL libraries] 项目的 https://micronaut-projects.github.io/micronaut-sql/latest/guide/#hibernate[Configuring Hibernate] 章节。

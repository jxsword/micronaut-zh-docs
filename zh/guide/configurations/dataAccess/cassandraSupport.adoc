[TIP]
.使用 CLI
====
如果您使用 Micronaut CLI 创建项目，请提供 `cassandra` feature 以在项目中包含 Cassandra 配置：
----
$ mn create-app my-app --features cassandra
----
====

更多信息请参阅 https://micronaut-projects.github.io/micronaut-cassandra/latest/guide/[Micronaut Cassandra Module] 文档。

[[dataAccess]]
下表汇总了需要在构建中添加以启用它们的配置模块与依赖：

.数据访问配置模块
|===
|依赖|描述

|`io.micronaut.sql:micronaut-jdbc-dbcp`
|使用 https://commons.apache.org/proper/commons-dbcp/[Commons DBCP] 配置 SQL link:{jdkapi}/java.sql/javax/sql/DataSource.html[DataSource]

|`io.micronaut.sql:micronaut-jdbc-hikari`
|使用 https://github.com/brettwooldridge/HikariCP[Hikari Connection Pool] 配置 SQL link:{jdkapi}/java.sql/javax/sql/DataSource.html[DataSource]

|`io.micronaut.sql:micronaut-jdbc-tomcat`
|使用 https://tomcat.apache.org/tomcat-7.0-doc/jdbc-pool.html[Tomcat Connection Pool] 配置 SQL link:{jdkapi}/java.sql/javax/sql/DataSource.html[DataSource]

|`io.micronaut.sql:micronaut-hibernate-jpa`
|配置 Hibernate/JPA `EntityManagerFactory` bean

|`io.micronaut.mongodb:micronaut-mongo-reactive`
|配置 https://mongodb.github.io/mongo-java-driver-reactivestreams[MongoDB Reactive Driver]

|`io.micronaut.neo4j:micronaut-neo4j-bolt`
|为 https://neo4j.com[Neo4j] 配置 https://github.com/neo4j/neo4j-java-driver[Bolt Java Driver]

|`io.micronaut.sql:micronaut-vertx-mysql-client`
|配置 https://github.com/eclipse-vertx/vertx-sql-client/tree/master/vertx-mysql-client[Reactive MySQL Client]

|`io.micronaut.sql:micronaut-vertx-pg-client`
|配置 https://github.com/eclipse-vertx/vertx-sql-client/tree/master/vertx-pg-client[Reactive Postgres Client]

|`io.micronaut.redis:micronaut-redis-lettuce`
|为 https://redis.io[Redis] 配置 https://lettuce.io[Lettuce] 驱动

|`io.micronaut.cassandra:micronaut-cassandra`
|为 https://cassandra.apache.org[Cassandra] 配置 https://github.com/datastax/java-driver[Datastax Java Driver]

|===

例如，要添加对 MongoDB 的支持，请添加以下依赖：

.build.gradle
[source,groovy]
----
compile "io.micronaut.mongodb:micronaut-mongo-reactive"
----

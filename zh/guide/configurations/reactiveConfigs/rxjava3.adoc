要添加对 RxJava 3 的支持，请添加以下模块：

dependency:io.micronaut.rxjava3:micronaut-rxjava3[scope="compile"]

要使用 RxJava 3 HTTP 客户端，请添加以下依赖：

dependency:io.micronaut.rxjava3:micronaut-rxjava3-http-client[scope="compile"]

更多信息请参阅 https://micronaut-projects.github.io/micronaut-rxjava3/latest/guide/[Micronaut RxJava 3] 文档。

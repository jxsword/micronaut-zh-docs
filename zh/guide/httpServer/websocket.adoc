Micronaut 框架为创建 WebSocket 客户端与服务器提供了专门支持。pkg:websocket.annotation[] 包包含用于定义客户端与服务器的注解。

WARNING: 自 Micronaut Framework 4.0 起，`io.micronaut:micronaut-http-server` 不再传递依赖 `micronaut-websocket`。要使用 ann:websocket.annotation.ServerWebSocket[] 等注解，请将 `micronaut-websocket` 依赖添加到应用类路径：

dependency::micronaut-websocket[]

要允许某个配置的任意请求头，请不要在配置中包含 `allowed-headers` 键。

对于多个允许的请求头，将配置的 `allowed-headers` 键设置为字符串列表。

.CORS 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      enabled: true
      configurations:
        web:
          allowed-headers:
            - Content-Type
            - Authorization
----

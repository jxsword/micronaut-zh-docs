CORS 请求默认允许来自 https://developer.chrome.com/blog/private-network-access-preflight[专用网络] 的访问。要禁止来自本地网络的访问，请将 `allow-private-network` 选项设置为 `false`。

.CORS 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      enabled: true
      configurations:
        web:
          allow-private-network: false
----

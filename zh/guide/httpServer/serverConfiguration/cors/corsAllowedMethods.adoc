要允许某个配置的任意请求方法，请不要在配置中包含 `allowed-methods` 键。

对于多个允许的方法，将配置的 `allowed-methods` 键设置为字符串列表。

.CORS 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      enabled: true
      configurations:
        web:
          allowed-methods:
            - POST
            - PUT
----

默认情况下，当一个请求头有多个值时，会发送多个请求头，每个头一个值。可以通过设置配置选项，改为发送单个请求头并以逗号分隔的值列表。

[configuration]
----
micronaut:
  server:
    cors:
      single-header: true
----

CORS 请求默认禁用凭据。要允许凭据，请将 `allow-credentials` 选项设置为 `true`。

.CORS 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      enabled: true
      configurations:
        web:
          allow-credentials: true
----

要配置通过 `Access-Control-Expose-Headers` 头在对 CORS 请求的响应中发送的请求头，请在配置中为 `exposed-headers` 键包含一个字符串列表。默认不暴露任何请求头。

.CORS 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      enabled: true
      configurations:
        web:
          exposed-headers:
            - Content-Type
            - Authorization
----

自 Java 19 起，JVM 包含对 https://openjdk.org/jeps/425[虚拟线程（「Project Loom」）] 的实验性支持。由于这是一个预览特性，您需要传入 `--enable-preview` 作为 JVM 参数来启用它。

Micronaut 框架会检测虚拟线程支持，并在可用时将其用于名为 `blocking` 的执行器。如果不支持虚拟线程，该执行器将别名到 `io` 线程池。

=== 事件循环载体（Event loop carrier）

Micronaut HTTP Server Netty 4.9 引入了一种 *实验性* 模式，在 Netty 事件循环上运行虚拟线程。这可以提升虚拟线程的性能，因为它避免了 Netty 事件循环与 JDK ForkJoinPool 之间的上下文切换。

该模式需要访问 JDK 内部 API。请以 `--add-opens=java.base/java.lang=ALL-UNNAMED` 运行您的应用。然后为事件循环启用 `loom-carrier` 标志，例如 `micronaut.netty.event-loops.loom-carrier=true`

.启用事件循环载体
[configuration]
----
micronaut:
  netty:
    event-loops:
      default:
        loom-carrier: true
----

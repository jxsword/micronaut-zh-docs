处理阻塞操作时，Micronaut 框架默认将阻塞操作转移到一个无界的缓存 I/O 线程池。您可以使用名为 `io` 的 api:scheduling.executor.ExecutorConfiguration[] 来配置 I/O 线程池。例如：

.配置服务器 I/O 线程池
[configuration]
----
micronaut:
  executors:
    io:
      type: fixed
      nThreads: 75
----

上述配置创建了一个具有 75 个线程的固定线程池。

[[corsCrossOriginResourcePolicy]]
要配置 https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html#cross-origin-resource-policy-corp[Cross-Origin-Resource-Policy（CORP）] 响应头，请设置 `cross-origin-resource-policy` 选项。<<corsConfiguration,CORS>> 无需启用。

.CORP 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      cross-origin-resource-policy: same-origin
----

支持的值为 `same-origin`、`same-site` 与 `cross-origin`。

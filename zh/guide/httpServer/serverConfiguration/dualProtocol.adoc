Micronaut 框架支持同时绑定 HTTP 与 HTTPS。要启用双协议支持，请修改您的配置。例如：

.双协议配置示例
[configuration]
----
micronaut:
  server:
    ssl:
      enabled: true
      build-self-signed: true
    dual-protocol : true
----
- 必须配置 SSL 才能使 HTTPS 生效。本例中我们仅使用带 `build-self-signed` 的自签名证书，其他配置参见 <<https,用 HTTPS 保护服务器>>
- `dual-protocol` 同时启用 HTTP 与 HTTPS 是一项可选（opt-in）特性——设置 `dualProtocol` 标志即可启用。默认情况下，Micronaut 框架只启用其中一个。

也可以自动将所有 HTTP 请求重定向到 HTTPS。除了前面的配置，您还需要启用该选项。例如：

.启用 HTTP 到 HTTPS 重定向
[configuration]
----
micronaut:
  server:
    ssl:
      enabled: true
      build-self-signed: true
    dual-protocol : true
    http-to-https-redirect: true
----

- `http-to-https-redirect` 启用 HTTP 到 HTTPS 重定向

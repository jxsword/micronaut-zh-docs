[[corsCrossOriginEmbedderPolicy]]
要配置 https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html#cross-origin-embedder-policy-coep[Cross-Origin-Embedder-Policy（COEP）] 响应头，请设置 `cross-origin-embedder-policy` 选项。<<corsConfiguration,CORS>> 无需启用。

.COEP 配置示例
[configuration]
----
micronaut:
  server:
    cors:
      cross-origin-embedder-policy: require-corp
----

支持的值为 `unsafe-none`、`require-corp` 与 `credentialless`。

[[exceptionHandler]]
或者，您可以实现 api:http.server.exceptions.ExceptionHandler[]——一个用于处理 HTTP 请求执行期间发生异常的通用钩子。

IMPORTANT: 捕获某个异常的 `@Error` 注解优先于捕获同一异常的 `ExceptionHandler` 实现。

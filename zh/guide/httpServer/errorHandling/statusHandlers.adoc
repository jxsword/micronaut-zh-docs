ann:http.annotation.Error[] 注解支持定义异常类或 HTTP 状态。标注了 ann:http.annotation.Error[] 的方法必须定义在以 ann:http.annotation.Controller[] 标注的类中。该注解还支持全局与局部（local，默认）的概念。

局部错误处理器只响应因路由匹配到同一控制器中的另一个方法而抛出的异常。全局错误处理器可以因任何抛出的异常而被调用。在解析要执行的处理器时，总是先查找局部错误处理器。

TIP: 定义异常的错误处理器时，可以将异常实例作为方法参数指定，并省略注解的 exception 属性。

TIP: 更多信息请参阅 https://guides.micronaut.io/latest/micronaut-error-handling.html[错误处理] 指南。

从 `chain.proceed` 返回的发布者不应发出错误。在上游过滤器发出错误或路由本身抛出异常的情况下，应发出错误响应而不是异常。某些情况下，您可能希望了解错误响应的原因；为此，如果响应是因异常被发出或抛出而创建的，响应上会存在一个属性。原始原因存储在属性 api:http.HttpAttributes#EXCEPTION[] 中。

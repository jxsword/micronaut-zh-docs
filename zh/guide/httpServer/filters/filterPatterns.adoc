过滤器模式可以定义在过滤器类上（api:http.annotation.Filter[]、api:http.annotation.ServerFilter[] 或 api:http.annotation.ClientFilter[] 注解），或定义在过滤器方法上（api:http.annotation.RequestFilter[] 或 api:http.annotation.ResponseFilter[] 注解）。

您可以通过设置 `patternStyle` 使用不同风格的模式进行路径匹配。默认使用 api:core.util.AntPathMatcher[] 进行路径匹配。使用 Ant 风格时，映射按以下规则匹配 URL：

* ? 匹配一个字符
* * 匹配零个或多个字符
* ** 匹配路径中的零个或多个子目录

.@Filter 注解路径匹配示例
|===
|模式|匹配路径示例

|`/**`
|任意路径

|`customer/j?y`
|customer/joy、customer/jay

|`customer/*/id`
|customer/adam/id、customer/amy/id

|`customer/**`
|customer/adam、customer/adam/id、customer/adam/name

|`customer/**/*.html`
|customer/index.html、customer/adam/profile.html、customer/adam/job/description.html
|===

另一种选择是基于正则表达式的匹配。要使用正则表达式，请设置 `patternStyle = FilterPatternStyle.REGEX`。`pattern` 属性应包含一个正则表达式，它需要精确匹配所提供的 URL（使用 link:{jdkapi}/java.base/java/util/regex/Matcher.html#matches--[Matcher#matches]）。

NOTE: 推荐使用 `FilterPatternStyle.ANT`，因为其模式匹配比使用正则表达式性能更好。当您的模式无法用 Ant 风格正确表达时，应使用 `FilterPatternStyle.REGEX`。

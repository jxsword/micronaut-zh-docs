Micronaut 控制器 action 默认产出 `application/json`。不过，您可以使用 `@Produces` 注解或 HTTP 方法注解的 `produces` 成员来更改响应的 `Content-Type`。

snippet::io.micronaut.docs.server.response.ProducesController[tags="imports,clazz", indent=0]

<1> 默认内容类型为 JSON
<2> 在控制器 action 上标注 `@Produces` 以更改响应内容类型。
<3> 设置方法注解的 `produces` 成员同样会更改内容类型。

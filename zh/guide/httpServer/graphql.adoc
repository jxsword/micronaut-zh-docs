https://graphql.org/[GraphQL] 是一种用于构建 API 的查询语言，它提供直观灵活的语法，以及描述数据需求与交互的系统。

有关如何使用 Micronaut 构建 GraphQL 应用的更多信息，请参阅 https://micronaut-projects.github.io/micronaut-graphql/latest/guide[Micronaut GraphQL] 文档。

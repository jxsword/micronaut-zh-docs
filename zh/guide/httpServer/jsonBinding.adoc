[[jsonBinding]]
如今最常见的数据交换格式是 JSON。

默认情况下，api:http.annotation.Controller[] 注解指定 Micronaut 框架中的控制器默认消费与产出 JSON。

自 Micronaut Framework 4.0 起，用户必须选择希望使用哪种序列化方式（Jackson Databind 或 Micronaut Serialization）。两种方式都支持使用 https://micronaut-projects.github.io/micronaut-serialization/latest/guide/index.html#jacksonAnnotations[Jackson Annotations]。

无论采用哪种方式，Micronaut 框架都以非阻塞方式读取传入的 JSON。

[[runningSpecificPort]]
默认情况下，服务器运行在 8080 端口。不过，您可以将服务器设置为运行在特定端口上：

[configuration]
----
micronaut:
  server:
    port: 8086
----

TIP: 这也可以通过环境变量配置，例如 `MICRONAUT_SERVER_PORT=8086`

要运行在随机端口上：

[configuration]
----
micronaut:
  server:
    port: -1
----

TIP: 如果多个服务器在同一端口上同时启动，设置显式端口可能导致测试失败。为避免这种情况，请在测试环境配置中指定随机端口。

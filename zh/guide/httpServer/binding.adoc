上一节的示例演示了 Micronaut 框架如何让您从 URI 路径变量绑定方法参数。本节展示如何从请求的其他部分绑定参数。

== 绑定注解

所有绑定注解都支持通过其 `name` 成员自定义要绑定来源的变量名。

下表汇总了这些注解及其用途，并提供了示例：

.参数绑定注解
|===
|注解|说明 |示例

|link:{api}/io/micronaut/http/annotation/Body.html[@Body]
|从请求体绑定
|`@Body String body`

|link:{api}/io/micronaut/http/annotation/CookieValue.html[@CookieValue]
|从 cookie 绑定参数
|`@CookieValue String myCookie`

|link:{api}/io/micronaut/http/annotation/Header.html[@Header]
|从 HTTP 请求头绑定参数
|`@Header String requestId`

|link:{api}/io/micronaut/http/annotation/QueryValue.html[@QueryValue]
|从请求查询参数绑定
|`@QueryValue String myParam`

|link:{api}/io/micronaut/http/annotation/Part.html[@Part]
|从 multipart 请求的某个部分绑定
|`@Part CompletedFileUpload file`

|link:{api}/io/micronaut/http/annotation/RequestAttribute.html[@RequestAttribute]
|从请求的属性绑定。属性通常在过滤器中创建
|`@RequestAttribute String myAttribute`

|link:{api}/io/micronaut/http/annotation/PathVariable.html[@PathVariable]
|从请求路径绑定
|`@PathVariable String id`

|link:{api}/io/micronaut/http/annotation/RequestBean.html[@RequestBean]
|将任意 Bindable 值绑定到单个 Bean 对象
|`@RequestBean MyBean bean`
|===

snippet::io.micronaut.docs.server.binding.MovieTicketBean[tags="class", indent=0, title="Bean definition"]

bean 类必须用 `@Introspected` 内省。它可以是以下之一：

. 带 setter 与 getter 的可变 Bean 类
. 带 getter 与全参构造器的不可变 Bean 类（或在构造器或静态方法上标注 `@Creator` 注解）。构造器的参数必须与字段名匹配，以便无需反射即可实例化对象。

WARNING: 由于 Java 不会在字节码中保留参数名，必须使用 `-parameters` 编译代码，才能使用来自其他 jar 的不可变 bean 类。另一种选择是在您的源码中扩展该 Bean 类。

== 变量解析

Micronaut 框架尝试按以下顺序填充方法参数：

. URI 变量，例如 `/{id}`。
. 如果请求是 `GET` 请求，则从查询参数绑定（例如 `?foo=bar`）。
. 如果存在 `@Body` 且请求允许携带请求体，则将请求体绑定到它。
. 如果请求可以有请求体且未定义 `@Body`，则尝试解析请求体（JSON 或表单数据），并从请求体绑定方法参数（参见示例）。
. 最后，如果无法填充方法参数，返回 `400 BAD REQUEST`。

snippet::io.micronaut.docs.server.binding.PointController[tags="class", indent=0, title="Binding Method Arguments From Body with no `@Body`"]

<1> JSON 请求体绑定到控制器方法参数，例如 '{"x":10,"y":20}'（"application/json"）
<2> 表单数据也可以，例如 'x=10&y=20'（"application/x-www-form-urlencoded"）

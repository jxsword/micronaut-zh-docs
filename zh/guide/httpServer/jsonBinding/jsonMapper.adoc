您可能熟悉 https://fasterxml.github.io/jackson-databind/javadoc/2.7/com/fasterxml/jackson/databind/ObjectMapper.html[Jackson 的 `ObjectMapper`]。对于与实现无关（implementation-agnostic）的应用代码，我们建议依赖 api:json.JsonMapper[]——它是 Micronaut 面向常见映射操作的 JSON 抽象。<<jsonBinding,Micronaut Serialization 与 Micronaut Jackson Databind>> 都提供了 api:json.JsonMapper[] 的实现，Micronaut Serialization 还定义了自己的 `ObjectMapper` 接口，扩展自 api:json.JsonMapper[]。

如果您有意编写与特定实现相关的代码，仍然可以使用相应的实现 API，例如 Jackson 的 `ObjectMapper` 或 Micronaut Serialization 的 `ObjectMapper`。

您可以注入类型为 `JsonMapper` 的 bean，或通过 `JsonMapper.createDefault()` 手动实例化一个。

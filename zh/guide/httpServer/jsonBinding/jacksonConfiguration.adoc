如果您使用 <<jsonBinding,`micronaut-jackson-databind`>>，可以通过 api:io.micronaut.jackson.JacksonConfiguration[] 类经配置来设置 Jackson `ObjectMapper`。本节内容仅针对 Jackson 实现；对于应保持跨 Micronaut JSON 实现可移植的应用代码，建议依赖 api:json.JsonMapper[]。

所有 Jackson 配置键都以 `jackson` 开头。

|=======
| dateFormat | String | 日期格式
| locale     | String | 使用 link:{jdkapi}/java.base/java/util/Locale.html#forLanguageTag-java.lang.String-[Locale.forLanguageTag]。示例：`en-US`
| timeZone   | String |使用 link:{jdkapi}/java.base/java/util/TimeZone.html#getTimeZone-java.lang.String-[TimeZone.getTimeZone]。示例：`PST`
| serializationInclusion | String | link:{jackson-annotations}com/fasterxml/jackson/annotation/JsonInclude.Include.html[JsonInclude.Include] 之一。示例：`ALWAYS`
| propertyNamingStrategy | String | link:{jackson-databind}com/fasterxml/jackson/databind/PropertyNamingStrategy.html[PropertyNamingStrategy] 实例的名称。示例：`SNAKE_CASE`
| defaultTyping          | String | 用于多态类型处理的全局 defaultTyping，取自枚举 link:{jackson-databind}com/fasterxml/jackson/databind/ObjectMapper.DefaultTyping.html[ObjectMapper.DefaultTyping]。示例：`NON_FINAL`
|=======

示例：

[configuration]
----
jackson:
  serializationInclusion: ALWAYS
----

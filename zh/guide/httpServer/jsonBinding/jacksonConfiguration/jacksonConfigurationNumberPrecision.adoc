在 JSON 解析期间，框架可能会将任何传入数据转换为中间对象模型。默认情况下，该模型对数值使用 `BigInteger`、`long` 与 `double`。这意味着 `BigDecimal` 本可表示的一些信息可能丢失。例如，具有许多小数位、无法用 `double` 表示的数字可能被截断，即使反序列化的目标类型使用 `BigDecimal` 也一样。关于末尾零数量的元数据（`BigDecimal.precision()`）——例如 `0.12` 与 `0.120` 之间的差异——也会被丢弃。

如果您需要对数字类型保持完整精度，请使用以下配置：

[configuration]
----
jackson:
  deserialization:
    useBigIntegerForInts: true
    useBigDecimalForFloats: true
----

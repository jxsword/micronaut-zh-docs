如果您使用 <<jsonBinding,`micronaut-jackson-databind`>>，所有 Jackson 特性都可以用特性名作为键、用布尔值表示启用或禁用来配置。属性名请查阅配置参考。

示例：

[configuration]
----
jackson:
  serialization-features:
    indentOutput: true
    writeDatesAsTimestamps: false
  deserialization-features:
    useBigIntegerForInts: true
    failOnUnknownProperties: false
----

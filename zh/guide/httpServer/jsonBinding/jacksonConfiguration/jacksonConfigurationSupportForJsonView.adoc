如果您使用 <<jsonBinding,`micronaut-jackson-databind`>>，只要在配置文件（例如 `application.yml`）中将 `jackson.json-view.enabled` 设置为 `true`，就可以在控制器方法上使用 `@JsonView` 注解。

Jackson 的 `@JsonView` 注解让您能够按响应控制暴露哪些属性。更多信息参见 https://www.baeldung.com/jackson-json-view-annotation[Jackson JSON Views]。

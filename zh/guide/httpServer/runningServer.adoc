<1> 运行 `EmbeddedServer`，Spock 的 `@AutoCleanup` 注解确保在规约完成后停止服务器。
<2> `EmbeddedServer` 接口提供被测服务器的 `URL`，该服务器运行在随机端口上。
<3> 测试使用 Micronaut HTTP 客户端发起调用
<4> `retrieve` 方法以 `String` 形式返回控制器的响应

IMPORTANT: 未显式配置端口时，端口为 8080，除非应用在 `test` 环境下运行（此时端口为随机值）。当应用上下文从测试类的上下文启动时，会自动添加 test 环境。

Kubernetes 是一个容器运行时（container runtime），具备诸多特性，其中包括集成的服务发现与分布式配置。

Micronaut 框架包含与 Kubernetes 的一流集成。更多详情请参阅 https://micronaut-projects.github.io/micronaut-kubernetes/latest/guide/index.html[Micronaut Kubernetes 文档]。

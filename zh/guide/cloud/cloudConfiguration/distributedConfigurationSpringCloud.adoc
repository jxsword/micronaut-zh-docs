自 1.1 起，Micronaut 框架为尚未切换到 Consul 等更完整专用方案的用户提供了原生 https://spring.io/projects/spring-cloud-config/[Spring Cloud Configuration] 支持。

要启用分布式配置，请确保 <<bootstrap>> 已启用，并创建一个包含以下配置的 `src/main/resources/bootstrap.[yml/toml/properties]` 文件：

.集成 Spring Cloud Configuration
[configuration]
----
micronaut:
  application:
    name: hello-world
  config-client:
    enabled: true
spring:
  cloud:
    config:
      enabled: true
      uri: http://localhost:8888/
      retry-attempts: 4
      retry-delay: 2s
----

- `retry-attempts` 为可选，指定重试次数
- `retry-delay` 为可选，指定重试之间的延迟

Micronaut 框架使用所配置的 `micronaut.application.name`，从通过 `spring.cloud.config.uri` 配置的 Spring Cloud 配置服务器查找应用的属性源。

有关如何搭建服务器的更多信息，请参阅 https://spring.io/projects/spring-cloud-config/[Spring Cloud Config Server 文档]。
